# QQQ EMA V3.1-H3：Peak Profit Giveback 比例标签与多指标顶部验证研究计划

> 提案：用户 2026-11-13 新假设。**仅登记未来实验设计，目前尚未回测该新标签，不修改 frozen H3。**

## 1. 修正此前的结果标签：固定百分点 -> 利润回吐比例

[此前的量能衰竭实验](H3_量能衰竭与高浮盈回撤_2026-11-13.md)采用的**旧定义**是：峰值浮盈至少 20%，并且最终比峰值少至少 15 个百分点。这一定义仅用于此前历史结果的事后分组，不能将先前报告的 QQQ 4/60、GOOGL 13/58 解释为新定义的样本数。

今后优先使用如下新定义。对每笔已开仓交易：

- `R_peak(t)`：从实际买入以来，截至第 t 个**已完成收盘**能够观测到的历史最高*净可实现*浮盈（开/平仓费用模型与当前收益一致；不使用后来的最高价）。
- `R_now(t)`：截至 t 的*净可实现*收益（同一费用与复权口径）。
- `Giveback(t) = (R_peak(t) - R_now(t)) / R_peak(t)`，仅 `R_peak(t) > 0` 时定义；亏损或零正浮盈时标记 `undefined`，而非硬除以零。
- **事后重点审计事件**：如果截至该笔实际 H3 退出的 `Giveback(exit) >= 0.50`，定义为“吐回至少一半已获得的最大利润”。若严格“超过”则 `>0.50`，结果报告应明确使用哪个边界；主用 `>=`，另单列 `> ` 敏感性。
- `Giveback` **允许超过 100%**，这代表此前盈利全部吐光并且转亏，绝不可夹到 100%。
- 不再将“至少 15 个百分点”作为新研究的主标签。为抑制极小浮盈被噪声扭曲，按历史峰值净浮盈量级分层 `(0,5%]`、`(5,10%]`、`(10,20%]`、`>20%`，并在后续试验比较不同最小可研究浮盈门槛；不能事后选最漂亮门槛。
- 保存**连续标签**（Giveback ratio、退出相对峰值的股价回撤、金额与盈利保留率），不仅是二分类。

示例：峰值 +10%、退出 +4% => 吐回 60%；峰值 +60%、退出 +30% => 吐回 50%；峰值 +20%、退出 −5% => 吐回 125%。注意利润回吐百分比与价格从高点回撤百分比**不同**。

注意：**事后审计标签不是交易触发条件**。研究目标是找到截至每一日收盘可观察的早期风险信号，使其在后续发生 >=50% 利润回吐之前提示，而不是等到已经吐回 50% 才卖。并且单笔交易的最终标签可能依赖未来数据，只能用于**训练、评估或回放结果**，不得输入当天实时信号。

## 2. 候选顶部/趋势恶化信号（按独立信息来源分组）

| 类别 | 事前可观察候选特征 | 主要误报/失败模式 |
|---|---|---|
| 成交量参与度 | 5/20 日相对量、创新高量价背离、上涨日/下跌日成交量变化、OBV/CMF 变化 | 成交量缩小可能是惜售与健康盘整；宏观季节性；拆分/行情供应商量能定义 |
| 动量背离 | RSI(14) 看跌背离、MACD histogram 连续衰减、ROC 衰减 | RSI/MACD/ROC 与价格高度相关、对趋势股可连续背离而创新高 |
| 趋势结构破坏 | EMA5/10 死叉、价格跌破 EMA10/20、EMA 斜率转负、20 日高低点结构 | 趋势正常回调中高频假触发、提前卖飞 |
| 波动率与扩张 | ATR 相对价格上升、布林带扩张/收缩后方向破坏、回撤相对 ATR | 波动率上升也可能是上涨加速，而非顶部 |
| 高位派发 | 放量长上影、连续高位大成交量阴线、价格新高但弱收盘 | 长上影/放量不足以证明真实机构派发 |
| 市场广度与相对强弱 | QQQ 成分股创新高/均线上占比、QQQ vs SPY/RSP/SOXX 的相对变化、VIX（用于 ETF） | 高度相关、成分股历史生存者偏差、跨市场数据日期不一致 |

不宜把所有技术指标一次性简单相加或加权投票。先选**互补信息来源**（成交量、价格结构、波动率、广度）各一组，与纯价格指标作基准对照。统计 feature correlation 和增量预测/经济价值，以避免同一种价格动量被重复计分。

## 3. 未来实验顺序与验收

1. **重新标注，不改交易**：统一同一笔 H3 交易的截至当前动态 `Giveback(t)`、最终 `Giveback(exit)`；统计新标签下的全量事件、最高浮盈分层、分年代/牛熊期分布。标识样本量与最小浮盈门槛敏感性。以前固定阈值统计保持原样，标记为不同口径。
2. **不触发卖出的信号诊断**：对 H3 每一个完整已持仓日提取 features，按固定 5/10/20 交易日未来风险及最终标签评估提前预警能力。看大回吐召回、误报、提前天数、卖飞损失，并设同等信号频率下的纯 EMA/价格基准。
3. **离散候选组合**：单指标 -> 两类不同来源的序贯组合（例如高位缩量/动量衰减预警，随后放量下跌及价格破位确认），拒绝无约束的参数组合搜索。只用信号日收盘前已知资料，下一正常开盘撮合。
4. **完整状态机**：在 frozen H3 外创建单独研究叠加层，加入“早卖 -> 待确认重新入场”的严格可执行过程，禁止上帝视角的最低点买回。逐笔归因、手续费/滑点压力、最大回撤、CAGR、敞口、交易次数和 payoff ratio 对照原 H3。
5. **跨标的与样本外**：QQQ 与 GOOGL 首轮探索不代表通过；先锁定阈值/模型，在新标的、不同时期、包括失败个股上验证。避免 survivorship、look-ahead、数据重建与多重检验偏差。

### 失败条件优先

- 在同等卖出信号频率下不能显著优于纯 EMA 价格基准 => 量能或组合指标无增量。
- 即便对大回吐交易识别准确，但提前卖飞的长期上涨利润更大 => 不进入正式方案。
- 提前卖出有效，但重买滑点/额外佣金/漏掉上涨造成总账户收益或 MDD 恶化 => 不进入正式方案。
- 只在事后筛选少量峰值回吐交易里漂亮、在全量冻结 H3 交易或样本外不成立 => 不进入正式方案。

**当前状态：仅备忘、未运行新标签或多指标消融；冻结 H3 参数和既有量能实验原始结论都未更改。**
