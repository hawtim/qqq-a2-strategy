# QQQ 动态 N20：买入当天生效是否能阻止 2015 年跳空？

研究日期：2026-11-11；完整日线截至 2026-11-09。**独立样本内单变量实验，不修改正式第四方案及冻结 SMA A2。**

## 先讲结论

1. **原第四方案完全不变**：无论只给 FAST 入场开启首日保护，还是所有买点全部开启，2000—2026 年全部 59 笔交易、收益和每日权益都严格不变。44 次常规入场、15 次 FAST 入场，买入当天**没有**出现 EMA10/20 新死叉。
2. **月 EMA5 上升减速否决 + 允许延迟补买**的实验版出现**恰好一次**新增有效 N20 卖出：2015-08-18 FAST 买入当日短均线新死叉、收盘低于买入开盘价，08-19 开盘退出，净亏 **−0.7822%**；原路径 08-24 开盘退出净亏 **−15.4063%**。
3. 这一次避免 **14.6241 个百分点单笔损失**，让实验版终值从 **$712,742** 变成 **$835,957**，CAGR 从 **7.5886%** 变成 **8.2295%**，账户 MDD 从 **−24.7714%** 降至 **−19.6813%**。
4. 两种策略合计，**没有发现“首日 N20 提前杀掉后来盈利交易”的样本内案例**；但这只能说当前样本触发极少，不能证明错杀概率为零。
5. **必须降低结论置信度**：2015-08-18 两条 EMA 的差仅 **−$0.0009012**（当日约 $102.24 的价格）。对该日调整后收盘价做纯假设性的 **+$0.02** 微小扰动，死亡交叉会从 08-18 推迟到 08-19；原本没有 day0 保护的方案也在 08-20 N20 退出，期末跳升到 **$825,292**。研究结果高度依赖一个几乎贴合的 EMA 交叉日。

## 固定什么，只改变什么

- **全部不变**：历史 QQQ 复权 OHLC、月线入场过滤、FAST/常规准入、7% 收盘亏损止损、EMA20/60 新死叉退出、动态 N20 在趋势确认后延期、下一交易日开盘成交、单边 0.05% 手续费、零现金收益、全部持仓比例和出场优先级。
- **唯一区别**：买入当日 `age=0` 也允许 N20 检查：`EMA10<EMA20` 且**相较前日由上至下新死叉**，并且 `当日调整后收盘 < 该笔实际买入调整后开盘`，当日收盘发信号，**下一日开盘**才能卖出。
- 原版 `age=1..20` 及 FAST 动态确认期原封不动；所以新方案多包含买入当天，理论上最多检查 **买入日 + 原有20个完整交易日**。它是严格的“只新增当天检查”消融实验，**不是**另行测试“总共严格20个交易日、从第0天算起”的版本。
- `fast` 仅提前入场首日生效；`regular` 仅常规 EMA20/60 买入首日生效；`all` 两者生效；`none` 是原始保护时间。

两个完全独立的入场上下文：

1. `fourth_original`：正式第四方案，普通 EMA20/60 金叉与月 EMA5 向上前提下的 FAST 重新入场；不额外加月线斜率否决。
2. `month_slowdown_defer`：`up_slow_veto_1_abs` + `defer_rejected_gold=True`，即月 EMA5 上行斜率减缓时暂停买入，斜率过滤恢复且 EMA20/60 多头状态仍成立时可补买。这正是先前产生 2015 年 −15.41% 的实验版本。

QQQ 调整后日线覆盖 2000-01-03—2026-11-09，**6,961** 行。基线与独立原第四方案 `replay_dynamic` 的全部交易和每日权益完全一致：**$742,709.14 / MDD −25.9975% / 59 笔完成交易**。与此前公开快照 $742,702.78 仅有 $6.36 分红复权基准细微差异。未使用盘中、未来月线值、未来已知涨跌或虚构收盘成交。

### 2015 年的真实成交路径

| 日期 | 首日保护关闭（原实验） | FAST 首日保护开启 |
|---|---|---|
| 2015-08-17 收盘 | 日 EMA10/20 新金叉，发出 FAST 买入 | 同左 |
| 2015-08-18 开盘 | 买入 $102.586137（调整后） | 同左 |
| **2015-08-18 收盘** | EMA10/20 **重新死叉**；收盘 $102.198952，低于买价，但 `age=0` 不允许 N20 | **触发 N20**，待次日开盘卖出 |
| 2015-08-19 开盘 | 继续持仓 | **卖出 $101.885562，净 −0.7822%** |
| 2015-08-21 收盘 | 触发 7% 收盘止损 | 已空仓 |
| 2015-08-24 开盘 | **卖出 $86.868208，净 −15.4063%** | 已空仓 |

买入当日收盘相对入场价仅 **−0.3774%**，但趋势交叉已经发生。新方案的 2015 年这笔交易提前 **3 个交易日**成交，未承诺按 7% 止损价成交，仍包含开盘跳空和双边手续费。

完整逐笔交易对账：**FAST-only 仅这一笔 2015 年交易的卖出日期、原因、收益改变**；其余入场与退出时间一致。以后终值差异来自避开一次损失后持续使用较高的复利本金，**不能虚构为后面又新增多次成功止损**。

## “错杀”机会到底有多少？

这里“错杀”严格定义为：**新增的买入当天 N20 出场，若仍执行旧规则，本来会成为净盈利交易**。不把 EMA10/20 死叉等同于必卖，也不把未来最终亏损事后用于提前触发。

| 入场模型 | 全部买入 | FAST / 常规 | 买入当天新死叉 | 同时收盘低于买价、且未被更高优先级覆盖 | 新增首日 N20 卖出 | 对照旧路径最终获利的“错杀” |
|---|---:|---:|---:|---:|---:|---:|
| 原第四方案 | 59 | 15 / 44 | **0** | **0** | 0 | **0** |
| 月线减速 + 延迟补买 | 52 | 5 / 47 | **2** | **1** | **1**（2015 FAST） | **0** |

第二次新死叉是 **2026-09-02 的常规买入**，但当天收盘相对买入价为 **+0.3026%**，因此**不满足** N20 的“收盘低于买价”条件。即使启用 `all`，它也不应触发卖出。原规则最终该笔交易净收益 −1.66%，这是有意保留浮盈保护边界的一个反例。

不能因为在 **1 次触发中 0 次错杀**，推导出长期错杀率低。它只说明该机制是一个相当稀疏的路径边界修补，增量信息很有限。

## 高敏感性反证：一两美分能移动整笔交易

原始 2015-08-18 复权价格及信号：

- EMA10 = **102.24183082**；EMA20 = **102.24273202**；差 **−0.00090120 美元**。
- 前日 2015-08-17 差 **+0.00401904 美元**；所以按连续浮点值属于**几乎贴合、刚刚穿越**的两日金叉/死叉。
- 当前 EMA 更新系数差 `2/11 − 2/21 ≈ 0.08658`。理论上当天复权收盘价提高约 **$0.01041**，就足以把 08-18 的新死叉移到下一交易日。

下面仅为**合成价格敏感性情景**，不是说历史数据真的有错误，也没有替换或修改原始文件。仅对 2015-08-18 的 `adj_close` 人为加减几美分，重新计算全部 EMA 和完整持仓路径：

| 仅对 2015-08-18 收盘假设扰动 | 08-18 是否新死叉 | 08-19 是否新死叉 | 原 N20（禁首日）2015 卖出 / 单笔 | FAST 首日 N20 2015 卖出 / 单笔 |
|---|---|---|---|---|
| −$0.02 | 是 | 否 | 08-24 / −15.41% | 08-19 / −0.78% |
| 实际数据（无扰动） | **是** | **否** | **08-24 / −15.41%** | **08-19 / −0.78%** |
| +$0.01 | 是（极接近零） | 否 | 08-24 / −15.41% | 08-19 / −0.78% |
| **+$0.02** | **否** | **是** | **08-20 / −2.05%** | **08-20 / −2.05%** |

在最后一行，原方案无需开 day0，也会在买入后的第 1 个完整交易日根据**新死叉**退出；两者全周期终值都约 **$825,292**。可见原实验巨额亏损的发生条件非常特定：**FAST 金叉刚买入的同一天恰好又死叉，原 N20 又刚好排除了 day0**。这更像窗口定义与细微日线交叉顺序共同作用的结果。

## 子样本与解释边界

月线减速 + 延迟补买策略，开启 FAST day0 后：

| 时段 | 原累计收益 | 首日保护后 | 观察 |
|---|---:|---:|---|
| 2000—2003 | +17.23% | +17.23% | 没有发生变化 |
| 2004—2009 | +46.97% | +46.97% | 过滤 2007—2008 交易的效果来自月线 gate，**不是** day0 |
| 2010—2015 | +12.58% | **+32.04%** | 全部来自 2015 一笔 |
| 2016—2021 | +159.33% | +159.33% | 交易时序相同，资本底数不同 |
| 2022—2026 | +41.68% | +41.68% | 交易时序相同，资本底数不同 |

原模型 MDD −24.77% 出现在 **2016-06-17**；新模型 MDD −19.68% 出现在 **2023-03-10**。这说明历史最大回撤瓶颈转移了，并非以后每次下跌都更早止损。

**结论定位**：这是一个合理的执行状态机边界修补，可以保留为候选规则。真正未被验证的是跨数据源的 EMA 交叉鲁棒性、未来新买点的错杀概率，以及“买入日 + 20 个完整交易日”是否应改成严格总 20 日。**不能仅凭 2015 年这一笔就宣布新方案优于正式第四方案**，也不应因历史收益巨大改善立刻调整实盘逻辑。

运行（旧/新/增量原始行情均须使用合法私有本地副本）：

```bash

  --old /local/old/QQQ.csv --new /local/new/QQQ.csv \
```
