# H3 N10 构想：EMA5/10 与 EMA5/20 的利润保护、一次重入完整账户回测（2026-11-13）

> 研究状态：**独立实验，尚不升级 H3**。原始 H3 逻辑与其他结果文件未改。研究脚本：[h3_profit_n10_ema_guard_shadow_overlay.py](../../research/experiments/h3_profit_n10_ema_guard_shadow_overlay.py)。成功运行：[GitHub Actions 43356770832](https://github.com/hawtim/qqq-a2-strategy/actions/runs/43356770832)；[完整派生交易、逐日权益与全部 signal actions ZIP artifact](https://github.com/hawtim/qqq-a2-strategy/actions/runs/43356770832/artifacts/14006606506)。

## 1. N20 为何不保护浮盈

源代码 `research/experiments/a2_month_ema5_slope_regime.py` 的 `n20_hit` 要求：`n20_active AND EMA10/20 death cross AND adj_close < 原买入 adj_open`。常规前20日有效；部分 REGULAR 有条件延到第30日，FAST 交易按慢趋势确认动态延长；所有分支都要求当时**已低于建仓价**。所以“最高赚50%后跌到只赚10%”不满足 N20，即使趋势恶化；正常 EMA20/60 死叉、7%净亏损收盘止损仍有效。利润保护不能直接叫 N20 的替换版。

用户提出“利润保护 N10”语义有歧义。本次**明确解释为：买入至少满10个交易日后，若最高浮盈已达10%或20%，出现快速均线死叉就允许另行保护利润；不是在前10天内单独止损**。这是可研究的候选定义，不是 H3 原定策略。

## 2. 精确执行模型

- 全部入场和退出依旧由独立的 **H3 frozen shadow state machine** 计算，不能由 overlay 改变原始 N20、FAST Eligibility、月线过滤及最终 EMA20/60 卖出时间。
- 入场第10个已完成交易日之后、截至当日收盘历史最高毛浮盈≥10%（P10）或≥20%（P20），目前收盘仍盈利、EMA20>EMA60，且 **EMA5 当日下穿 EMA10 或 EMA20**，允许产生 overlay 特殊卖出信号；次一正常交易日复权开盘全部卖出。
- 额外卖出后如果 EMA5 再次**上穿 EMA10**（主要对照；也测上穿 EMA20）且 EMA20>EMA60，则次一正常开盘用全部现金买回。若到原 H3 退出时仍未重新买入，现金继续闲置至下一次**原 H3**买入。**每笔原始 H3 最多一次特殊卖出＋一次重新买入，不重复交易。**
- 中周期 reentry **只要求 EMA20>EMA60，未额外要求月线进场 veto 放行**。这属于独立 overlay 的特殊重入授权；未来若保留原 H3 月线风险风格，应单独测试要求月线同意重入的控制组。不得声称这种重入和原始 H3 FAST 规则完全相同。
- 全现金无息、初始$100,000、单边0.05%费用、无税与额外滑点；收盘决定、次日常规开盘执行。使用同一 Yahoo adjusted OHLC 数据源快照；日报表内所有收益为历史样本内估计。
- **验证**：模拟器在 `H3_FROZEN` 无候选状态下每日权益、期末权益、CAGR、MDD、仓位敞口都与冻结 H3 引擎逐日匹配，容差<$0.05。正因为这个控制严谨，其余差异可以归因于 overlay 操作与费用（不是在某个版本中偷偷改变 H3）。

## 4. 交易频率与“少数交易改进”的归因

### QQQ P10 EMA5/20 卖、EMA5/10 买

- 基础 H3 60 笔完成交易中，28 笔曾额外退出一次，18 笔成功重买，10 笔一直现金至 H3 原退出。**额外成交46次/约26.9年**，约1.7笔交易执行动作/年；已经不是每笔都极少干预，但仍是低频。
- 虽然净账户表现更好，**只有11/28笔实际改善、17/28笔更差**。说明收益依赖「少数大幅避免回撤」超过「大量小幅卖飞」，不能用总体盈亏比伪装成高命中率。
- 最大改善示例：2010-03-02～2010-05-21，原H3 -4.18%，使用overlay +5.16%，单笔 +9.35pp；2019-10-02～2020-03-10，原 H3 +8.25% → overlay +16.65%，+8.40pp；2024-06-04～2024-08-07，原 H3 -1.35% → overlay +6.31%，+7.66pp。
- 最大卖飞示例：2026-04-10～08-03，原 H3 +12.51% → overlay +5.89%，**-6.62pp**；2001-10-15～2002-02-05，原 +7.13% → overlay +0.57%，**-6.56pp**；2009-03-31～2010-02-09，原 +42.96% → overlay +38.24%，**-4.72pp**。
- 分入场年代累计相对H3复利因子（非逐年CAGR）：2000–09 **0.975**、2010–19 **1.238**、2020–26 **1.007**；总因子 **1.215**。说明主要增益集中在2010年代，不能将整个历史的+21.5%解读为每个时代稳定有效。

### GOOGL P20 EMA5/10 卖、EMA5/10 买

- 20次额外提前卖、15次重买、5次直到原H3退出仍空仓。改善10笔、损害10笔。
- 好例子：2012-07-27～11-09，原H3 +5.67% → overlay +21.36%，+15.69pp；2024-04-02～08-07，原+5.06% → overlay +19.22%，+14.15pp；2024-10-02～2025-02-26，原+5.21% → overlay +14.82%，+9.60pp。
- 坏例子：2015-07-14～2016-01-28，原+28.36% → overlay +17.47%，**-10.89pp**；2013-10-17～2014-04-08，原+21.83% → overlay +14.60%，-7.23pp；2025-05-29～2026-03-09，原+69.59% → overlay +64.29%，-5.30pp。
- 按入场时期分段对H3相对复利因子：2000年代0.979、2010年代1.055、2020～26年1.294，主要增益聚集于最近一段。

## 5. 决策与下一轮验证

1. **验证成功的是「平行利润保护存在增量机会」的可能性，而不是任意短期均线死叉都可止盈。** 单独EMA5/10快速卖出，对QQQ在P10、P20都拉低CAGR；EMA5/20缓一点的卖出在P10适用于QQQ，在GOOGL不适用。
2. 交易次数依然增加，结果不满足「每笔交易最多只有很少操作」的严格标准，特别是P10触发28/60 QQQ、27/58 GOOGL笔，约近半交易；应研究择机减少触发频率，而不是更快的价格指标。
3. **最大回撤改善不明显**：QQQ P10 5/20 仅从 -24.30%到 -23.94%，GOOGL P20 5/10 MDD反而从 -35.49%到 -38.41%；如果风险优先，该结果远不够。
4. **不能因为选中两组当前样本内的历史收益赢家，就宣称优于冻H3**。目前只有两只标的且两个起始周期不同，另有供应商调整、额外滑点、税、当日大幅跳空、低频市场行为变化等重要风险。
5. 下一阶段最有价值：保留最少候选（比如P10 5/20卖＋5/10买），只在**量能/波动率明显恶化、且已出现足够大的浮盈保护价值**时执行。然后以**相同额外卖出次数**与不加其他指标的纯均线对照，最终仍以QQQ完整账户CAGR、MDD、Payoff、与同期B&H比较。也需要限制每轮一次干预，避免被洗出场。
6. 另加严格H3月线同意重新入场条件作为风险风格控制，以及样本外资产和时间拆分测试。若没有较好的增量，保留H3 frozen不变。
