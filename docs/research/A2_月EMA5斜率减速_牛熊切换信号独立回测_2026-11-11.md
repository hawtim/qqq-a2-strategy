# QQQ 第四方案：月 EMA5 斜率减速能否识别牛熊切换？

研究日期：2026-11-11。研究状态：**独立样本内实验，不改动正式第四方案，不选择新“最优规则”**。

## 研究问题与预先约定

原第四方案在 2007-12-06、2007-12-24 两次 EMA20/60 金叉时，所能见到的上个完整月 EMA5 虽然还在上行，但上涨速度已经放缓。2009-03-30 金叉时，月 EMA5 仍下行，然而下跌速度逐渐缓和。

测试两个互补的假设：

1. **向下减速，可能是熊转牛**：当上个完整月的月 EMA5 仍下行，却出现连续月度斜率改善时，允许常规 EMA20/60 金叉入场；避免“月线必须向上”错过 2009。
2. **向上减速，可能是牛转熊**：当上个完整月的月 EMA5 仍上行，但斜率下降时，拒绝或暂缓入场；试图过滤 2007 年 12 月。

上述信号也会在正常牛市调整中出现，因此事先规定主评判为：相对第四方案的期末资产、账户日度最大回撤、单笔最坏亏损、市场暴露、交易次数与各子样本时期表现；2007/2009 只是事后诊断，不能作为唯一胜负标准。

## 数据、执行与基线验证

- QQQ 2000-01-03 至 **2026-11-09**，共 6,961 个完整历史交易日；日 OHLC 使用同一复权基准。1999 年起预热指标。
- 前两段来自仓库 `docs/DATA_SOURCES.md` 指向的历史 QQQ 来源；2026-07-14～11-09 与 7 月重叠记录使用 StockQuote.io 2026-11-09 下载快照，本地统一复权。
- 重叠 8 个交易日，未复权 Close 最大差异 $0；旧序列复权因子 `0.9989590849727128`，最大比值偏差 `6.34×10⁻⁸`。旧原始行情和增量行情均不提交 Git。
- 初始 $100,000；全仓/空仓；单边手续费 0.05%；现金 0%，不计税、滑点；信号日收盘后决定，次日开盘成交。
- **基准第四方案与原 `replay_dynamic` 逐笔交易及每日权益严格一致**。期末 `$742,709.14`、CAGR `7.7538%`、MDD `−25.9975%`、59 笔已完成交易。与正式 GitHub 快照 `$742,702.78` 的差约 `$6.36`，来自新下载数据复权基准的微小差异，在预设的 `$15` 容差内。
- 不修改动态 N20、7% 收盘止损、EMA20/60 死叉退出。原第四方案 FAST 通道仍须满足“上个完整月 EMA5 向上 + 日 EMA10/20 新金叉”；新 gate 只控制新的买入，不会更改**持仓中**日 EMA20/60 金叉的趋势确认逻辑。

## 信号的精确定义

月末 EMA5：`E[m] = (Close[m] + 2 E[m-1]) / 3`。注意 `E[m]` 为当月真正结束后才能确定的值。

上一个**已完成**的月线斜率为 `d = E[m-1] − E[m-2]`；其上一期斜率为 `p = E[m-2] − E[m-3]`，再上一期为 `pp = E[m-3] − E[m-4]`。信号日在月份 `m` 内，只能使用 `d/p/pp`，不能使用本月最终收盘。

| 简称 | 硬过滤规则 | 研究问题 |
|---|---|---|
| 基线 | 不加新月线 gate | 冻结第四方案 |
| `up_only` | `d > 0` | 原始“月线必须向上” |
| `down_relief_1_abs` | `d > 0`，或者 `p < d < 0` | 允许一个完整月的下降减速 |
| `down_relief_2_abs` | `d > 0`，或者 `pp < p < d < 0` | 允许连续两个完整月下降减速 |
| `down_relief_2_pct` | 同上，但将每期斜率改为相对前一期 EMA 的百分比 | 检查原始美元变化和相对跌速是否矛盾 |
| `up_slow_veto_1_abs` | 若 `0 < d < p`，禁止新入场；其余允许 | 上升斜率单月变缓是否提示顶部风险 |
| `up_slow_veto_2_abs` | 若 `0 < d < p < pp`，禁止新入场；其余允许 | 顶部风险要求连续两次减速 |
| `both_1_abs` / `both_2_abs` | 向上减速否决 + 向下减速放行，两种条件组合 | 牛熊切换双向 gate |
| `mtd_*` | 用**信号当天已完成日收盘价**推算“临时本月 EMA”并比较斜率 | 更及时但可能日内随日期重画的月线信号 |

每个硬过滤版本只在“新金叉出现时”决定是否入场；拒绝后须等下一次**新金叉**。`__defer` 对照版本则在新金叉被拒绝后维持等待状态，只有 EMA20 始终高于 EMA60 且 gate 后续恢复时才在下一开盘买入，若趋势死叉先发生则取消等待。此区别会显著改变漏接长期趋势的数量。

## 2007—2009 的逐信号判别

表中“拦下”指新金叉在当时的准入 gate 为假，不保证最终账户没有其他先前持仓；逐笔仓位流参见 CSV。

| 原金叉日 | 第四方案结果 | 月线方向/变化 | 上升减速否决 | 连续两月下降减速放行 | 组合 |
|---|---:|---|---|---|---|
| 2007-12-06 | −4.02% | 向上但减速，`+1.825 → +0.154` | **拦下** | 允许 | 拦下 |
| 2007-12-24 | −4.55% | 同上 | **拦下** | 允许 | 拦下 |
| 2008-04-21 | −4.18% | 下降减速但不连续两月 | 允许 | **拦下** | 拦下 |
| 2008-08-14 | −6.05% | 下降减速但不连续两月 | 允许 | **拦下** | 拦下 |
| 2009-03-30 | +42.96% | 绝对下降斜率逐月收窄，约 `−1.918 → −1.474 → −1.422` | 允许 | **允许** | 允许 |

这是机制上的积极证据：**一个纯粹的月 EMA5 斜率二阶变化，恰好可以区分这五个已知案例。** 但这五笔属于同一次熊市过程，不能当作五次独立成功检验。

特别反证：2009 年 1 月至 2 月的**绝对美元变化**略有放缓，但**百分比月斜率**从 `−5.00%` 恶化到 `−5.08%`，因此 `down_relief_2_pct` **不能在 2009-03-30 放行**。定义一换，结果就变化。基于历史图形选择单位可能构成过拟合。

另外，临时当月 EMA（MTD）在这些信号日期都没有形成可用的拒绝组合；“本月月线减速”更敏感，但在实际历史样本并没有提升完整策略。

## 为什么“排除四次失败、保留 2009 大赢家”仍然惨败？

1. **金叉是稀缺事件，不是每天持续的多头状态。** 硬性否决一个正确金叉后，不能随意几天后“补上”。完整趋势可能一直没有新 EMA20/60 金叉，因而长期空仓；多个版本全年市场暴露降至 20%～50%，远低于基线约 68%。
2. **2007 不是唯一熊牛转换期。** 在 2010—2015 年，冻结第四方案区间收益约 **+34.0%**；上升减速单月否决 + 延后买入约 **+12.6%**。避开 2007 年两次失败，也损失了其他年份成功的早期上车机会。
3. **入场价格与跳空风险同时变了。** 上升减速单月否决 + 延后买入虽把全周期 MDD 降到 −24.77%，但其最差单笔交易约 **−15.41%**（2015 年跳空后次日开盘成交）；原第四方案最差单笔约 **−8.32%**。不能只看 MDD 一项。
4. **路径依赖使“少亏一笔”的复利不一定正向。** 被拒绝的交易可能改变之后是否有持仓、哪些日 EMA10/20 金叉可做 FAST、下一次 EMA20/60 金叉是在持仓内还是空仓内。因此不能简单把 4 个原始亏损百分数从收益曲线里减掉。

跨子样本的进一步反例：2004—2009 年的“上行减速 1 月否决 + 延后买入”收益约 **+47.0%**，高于原第四方案约 **+33.3%**，期间 MDD 从约 −26.0% 降至 −19.2%；但这种优势没有延续到 2010—2015 年。风险改善高度依赖选择的历史阶段。

## 研究结论与可证伪边界

- 月 EMA5 的一阶/二阶斜率**确实提供了事后解释 2007/2009 买点的结构信息**，其合理用途可能是金叉质量的辅助评分。
- 把它升级为“必须满足的买入条件”会产生显著机会成本；多个严格版本失去的复利远超少数被过滤的损失。
- 本次是探索性**样本内**结果，2007/2009 是提出假设时就看到的历史案例，不具备独立验证资格。
- 不修改正式第四方案，不把任何实验中的单项优势宣传为策略完成；下一步若继续，可以预先冻结具体逻辑，在 SPY/IWM 或不同起点做不调参验证，再决定是否作为软评分纳入预警系统。
