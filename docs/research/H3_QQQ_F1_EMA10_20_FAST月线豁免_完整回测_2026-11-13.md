## 一、研究动机及边界

从 H3 2010 年后 **39 段空仓、965 交易日**与其中 **47 次新 EMA10/20 FAST 金叉、32 次被月线状态拒绝**的归因出发，检验：「限制在原 H3 因 EMA20/60 死叉退出之后，且上一完整月月 EMA5 仍正斜率、只是上升减速的情形，能否根据 FAST 信号及价格结构有限提前放行，而不必等待月线重新合格？」

**已有反例与识别偏差：** 前面的全月线放宽、EMA200 过滤、R1 日线 EMA20/60 金叉等方案均未同时改善账户收益和风险。本轮采用新的 FAST 锚点，不再以提高持仓率为优化目标。所选 2014 年机会本身是提出假设的来源，**不是独立样本外验证**。

统一输入：QQQ 自 2000-01-03 严格自然启动至 2026-11-11（含更早数据进行均线预热），初始$100,000，单边交易费0.05%，**已完成收盘时产生信号，次一常规开盘成交**；全仓或现金；不计算额外滑点、现金收益、税。四个 F1 都运行完整 H3 真实持仓状态机（N20、首日3%收盘保护、7%收盘止损、EMA20/60慢死叉、FAST确认、月线延期状态与未来新入场资格全部按照新仓日重新运算），**不是影子仓位替换入场价**。

**校验：** F1 专属引擎“不开启任何例外”时，冻结 H3 的所有 60 笔交易、日度权益及是否持仓逐日完全一致，CAGR=9.8872%、MDD=−24.2999%。F1 新增入场不会阻止原 H3 本来允许的入场；对入场新规则不发真实券商订单。

## 二、仅四个事先固定的 FAST 入场候选

公共限定：

- 原 H3 / 当前变体账户确实空仓；
- 上一次**实际完成退出**原因为 `MA20/60 death cross`，非 N20、7% 亏损保护或入场首日止损；
- 本轮出场后有新的**日线 EMA10/20 金叉**，并且截至入场信号日维持 EMA10>EMA20；若后来 FAST 死叉则清除资格，需等待下一次新的 FAST 金叉；
- 上一个**已完整结束的月份**月 EMA5 斜率满足 `0<斜率本月<斜率上月`，原 H3 **全局月线减速 gate** 正在拦截；
- 不强制 EMA200（适用于新标的的冷启动研究）；若原 H3 已放行买入则原始规则优先，避免额外交易。
  
| 版本 | 具体特征（满足后次开盘买入） |
|---|---|
| **F1-0** | EMA10/20 **新鲜金叉当日**，直接定向豁免当前正斜率减速月线 veto |
| **F1-3** | FAST金叉当天计为第1日，至少连续3日 EMA10>EMA20，`Close>EMA20`；`(EMA10−EMA20)[t]>(EMA10−EMA20)[t−2]` 且 `(EMA20−EMA60)[t]>(EMA20−EMA60)[t−2]`。在第3日若尚不满足可继续等，只要期间不FAST死叉 |
| **F1-3 + BREAKOUT20** | F1-3 全部成立，同时 `Close[t]>max(Close[t−20:t−1])`（过去20交易日收盘最高点） |
| **F1-3 + SLOW BULL** | F1-3 全部成立，且`EMA20>EMA60`，进一步要求慢趋势也多头 |

注意三日的计数包括 FAST 金叉当日；信号可以在金叉后更晚的交易日首次成立，必须保证此前没有失效的 FAST 死叉。研究的是**FAST 入场本身**，不是把它变为 R1 的新鲜慢金叉入场。

最重要的取舍：

**仍然只有某些特定时期有价值。** 2010–2014中，F1-3阶段累计收益+39.65%，比H3的+28.03%更高；但2015–2019中它只有+75.05%，显著低于原H3+84.54%。2023年以来四种F1均落后H3，证实简单增加早买资格不能长期克服牛市踏空。

## 五、重要的一笔：2014年5月第一次FAST金叉其实是假的

| 方案 | 2014年5月实际新增买点 | 后续退出及收益 |
|---|---|---|
| **F1-0** | 5月2日FAST新金叉，5月5日开盘买入 | **5月9日**因N20退出，单笔 **−0.72%** |
| **F1-3** | 5月12日再次出现金叉，5月14日确认，**5月15日**开盘买入 | 10月16日退出，单笔 **+3.39%** |
| F1-3 + BREAKOUT20 | 5月19日满足突破，**5月20日**开盘买入 | 10月16日，**+2.84%** |
| F1-3 + SLOW BULL | 5月19日确认，**5月20日**开盘买入 | 10月16日，**+2.84%** |
| 原H3 | 月线放行较晚，**6月4日**开盘买入 | H3正常交易路径 |

F1-0的真实交易记录清楚表明**5月2日一次金叉并不代表上涨已经稳固**。三日方案买到的不是“原5月2日金叉后多等三天”的同一次信号——中间发生过EMA10/20死叉，5月12日重新金叉、计数重置。因此，FAST频繁的**金叉→死叉→再金叉**本身才是市场动摇的特征；确认规则能够偶尔避免第一次错误入场，但未能跨样本普遍奏效。

## 六、失败交易不会因为条件更严就消失

**2015年7月**：F1-0在7月16日因FAST放宽买入，8月24日以7%收盘止损，实际净亏**−15.41%**，再次证明次开盘跳空使7%规则不构成确定损失上限。F1-3与突破20日高点都在7月20日买入，8月14日N20退出，单笔亏**−3.39%**，并非完全规避。

**2004年4月**：F1-3在4月7日提前买入，5月3日因N20退出约**−5.47%**；更严格的价格确认也无法保证新的均线交叉走出趋势。

**2024年8月**：F1-3在8月22日买入、9月6日因N20退出约**−5.15%**；突破20日高点亦在同一日买入，价格突破并没有避免新的亏损。

**2026年8月（截至历史样本）**：F1-0于8月7日提前买入，9月3日N20退出约−1.39%；更严格F1-3+20日突破直到8月14日才买入，9月3日退出约**−3.17%**。更晚的确认价格甚至更贵，实际单笔损失扩大。

## 七、为什么不继续网格寻找“最佳金叉参数”？

基于多轮实验，近期值得接受的一项结构性认识：

- 日线均线交叉是**趋势状态变化的滞后结果**；在缓慢修复、剧烈反弹、牛市回调中会出现形态相似而后续收益相反的信号。
- 已测试的月线全放开、放宽其中一个闸门、上升EMA200门槛、慢线金叉0/3/5天确认、以及本轮FAST金叉/3天确认/20日突破/慢多头，均未得到“CAGR和MDD都改善”的稳健候选。
- F1前几笔获胜通常来自原H3已经会最终回补的趋势上涨，改动的额外成交费用与止损则是真实成本。反复把门槛微调为19/21/22日新高或2/4天确认，极易造成对QQQ **2000–2026单一样本**的过拟合。
- `EMA200` 对新上市标的还涉及200日预热与无长期历史的冷启动，不能作为所有标的的必要前提。

**下一研究决策**：不升为 H3 入场规则；坚持冻结 H3 与 A/B v1.0。把 FAST/F1/R1 的失败与成功交易按先前退出理由、市场波动/波幅、真正的入场后最大不利波动、是否很快出现反向死叉来解释，先检验**交易结构和环境是否可区分**，否则停止同一样本的局部均线调参；如要评估可泛化的收益，先使用 SPY、日经等跨标的或严格新阶段测试。
