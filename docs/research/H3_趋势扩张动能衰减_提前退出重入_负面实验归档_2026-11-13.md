# H3 研究归档｜趋势扩张、动能衰减退出与回调重入（2026-11-13）

**状态：停止推进 / 不纳入 H3 / 负面研究记录。** 本文记录前一轮对话中实际运行的 QQQ 日 K 独立覆盖层实验，避免以后重复研究。**策略主干、冻结 H3 及选定 V3 均不改变。**

## 研究假设

H3 已持仓且最高收盘浮盈至少 10% 时，如果 `T=(EMA20-EMA60)/ATR20 >= 2` 或 `E=(Close-EMA60)/ATR20 >= 5`，进入过度扩张观察；`M=(EMA10-EMA20)/ATR20` 自本轮观察峰值收缩至少 30%，并且连续恶化、收盘跌破 EMA10，则下一交易日调整后开盘退出。随后以 EMA10 重占、短期动能改善、最近 3/5 日高点突破或从最低价上涨 1 ATR 等规则重入。

**数据：** QQQ 上游 [jtang25/QQQ.csv](https://github.com/jtang25/Stock-Market-Index-Daily-Return-Distribution-/blob/main/QQQ.csv) 与 [jameswdonoghue/QQQ.csv](https://github.com/jameswdonoghue/QQQ-Data/blob/main/QQQ.csv) 合并，1999-03-10~2026-07-13 合计 6,877 完整日 K；2013-01-02 拼接；2,439 重叠日，重基准因子约 0.9758811548309515；为与 2026-11 H3 账本开盘价格对齐，统一乘 0.9989609457128912 的后续分红换基准因子。有效交易日从 2000-01-03 开始。禁止发布第三方原始日 K。

**执行与限制：** 仅修改冻结 H3 交易期间的附加卖出/买回（覆盖层），沿用冻结 H3 开仓与常规退出日期；收盘产生信号，下一常规开盘成交；初始 10 万美元，双向各 0.05% 佣金，空仓无收益，无税、额外滑点；日末权益计算 MDD。**覆盖层研究不是原生 Python H3 引擎交叉校验**，且历史样本内有参数选择与重复比较，不能视为独立验证。

## 五、研究结论及后续决定

1. EMA10/20 动能收缩确实可以被识别，但在强趋势中大量出现，**并非可靠的大回撤预测信号**。
2. 提高重入速度通常降低溢价，却不必然改善 CAGR；最佳买回溢价不等于最佳交易结果。
3. 有些个股可因基本面恶化出现永久资本损失；不宜把“下跌后必须买回”机制直接迁移至单股。
4. **用户决定先将该方向搁置。** H3 未来跨标的回测仅采用原 H3 完整入口/退出状态机，不携带本研究的新减仓、回调补仓规则。不要将本次的优化结果升级为 H3、V3 或实盘配置。
5. 未来若重新研究：先用外样本、跨股票、独立事件对照验证真正的价格结构破坏，再做回测；重点是趋势初始入场质量及利润保护，不强求同股买回。

**可追溯性**：详细实验在 ChatGPT 2026-11-13 的 QQQ 状态机研究中逐日执行；本报告为数据派生结果和研究摘要，不含第三方 OHLCV。由于未提交与原生 Python 对应的可运行覆盖层脚本，独立复现要求用户自备获授权行情并另外实现所述覆盖层，本报告不声称具备脚本级可复算性。
