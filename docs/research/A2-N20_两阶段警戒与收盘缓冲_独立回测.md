# QQQ A2-N20｜MA10/20死叉警戒 + 每日收盘亏损缓冲

研究时间：2026-11-09；样本2000-01-03至2026-07-13。使用相同复权日OHLC、初始资本$100,000、单边0.05%费用、现金零利息、不计额外滑点。原始A2-N20基准完全冻结，以下为一个独立的N20退出模块替换实验；未修改日MA20/60买入、日MA20/60常规退出、新金叉重入机制。

## 一、测试规则：确认后的两阶段状态机

第一阶段：入场后的第1—20个交易日，只要日MA10从上向下新穿MA20，就启动该笔仓位的`alert`状态。此阶段**不要求当日已经亏损**。

第二阶段：`alert`一旦启动，在该笔仓位结束前持续生效，**每日收盘**核查：

```
close < entry_price × (1 - buffer)
```

若满足，则次交易日开盘全仓卖出。若日MA20/60死叉也出现，则正常死叉退出优先。该机制并非盘中止损单，也不会因为低点触及阈值立刻卖；不能确保实际亏损被锁在`buffer`以内。全仓平仓后需等下次新的日MA20/60金叉。

特意区分此前错误理解的“只在MA10/20死叉当天检查亏损阈值”：当前版本是**死叉启动警戒，后续每天仍继续检查**。

## 五、初始化敏感性与结论

排除2000-01-03人工多头初始化，等待真实新日线金叉：原始A2完成58笔，Payoff3.99、MDD−20.29%；两阶段1.55%版本完成58笔，Payoff3.61、MDD−24.99%；两阶段4%版本Payoff2.54、MDD−26.24%。结论方向未变。

**结论：用户定义的“两阶段缓冲”能够显著降低此前“错过MA10/20交叉后再无保护”的漏洞，但1.55%不够救回2003年大赢家，扩大到3.82%又明显伤害整体策略风险。** 原始A2-N20仍保留为研究基准。参数已查看过全部历史，未做独立样本外验证，也没有在此轮修改重入机制。
