# QQQ A2-N20｜周 MA5/10 对称进出与周线退出实验

日期：2026-11-09。数据截至 2026-07-13。所有方案均使用相同的复权日 OHLC、初始资金 $100,000、单边手续费 0.05%、现金零利息和下一交易日开盘成交。无额外滑点。此为全样本探索，不是样本外验证。

## 研究问题

盈利之后改用周线 MA5/10 死叉止损，是否能降低持仓利润回吐，保住原始 A2 的大赢家？如果强调“怎么进就怎么出”，改用完整的周线 MA5/10 金叉买入、死叉卖出，结果是否更稳定？

周线由每个周五结束的自然交易周内最后一个实际交易日复权收盘价生成，MA5 与 MA10 是五周和十周**简单移动平均线**。周线金叉/死叉只能在完整周线收盘时确认，下一交易日开盘买卖。2026-07-13 是周一，最后一周尚未完成，不发出周线信号。周 MA5/10 大致相当于日 MA25/50，不完全等同原始日 MA20/60。

## 独立对照设计

1. **A2 原始基准**：日 MA20/60 金叉买、死叉卖，入场前20日亏损状态下日 MA10/20 死叉保护，卖出后等新日线金叉。
2. **日进周出**：保留 A2 日线金叉入场和 N20 保护；仅把常规日 MA20/60 死叉退出改成周 MA5/10 死叉退出；卖出后仍等新日线金叉。
3. **日进、两种死叉谁先触发先卖**：保留日线买入、N20和新日线金叉重入；常规退出是日 MA20/60 死叉或周 MA5/10 死叉，先触发者生效。这是将周线作为附加保护的独立实验。
4. **纯周线对称**：周 MA5/10 金叉全仓买，周 MA5/10 死叉全仓卖；重入等新周线金叉；不额外启用日线 N20 保护，体现真正的“怎么进就怎么出”。
5. **周线对称 + N20**：第4项增加原始 N20 保护。为检验早期止损是否能弥补周线确认延迟，单独报告，不将其称作纯周线对称。

## 原始大赢家保留情况

仅对相同日线金叉入场的“日进周出”版本进行逐笔一一映射。周线买入版本入场日期完全不同，不能把“未匹配原始入场日”解释成它的趋势收益为零。

|A2原买入日|A2原收益|周MA5/10退出后收益|
|---|---:|---:|
|2009-04-03|+34.94%|+34.10%|
|2016-12-13|+34.85%|+16.31%|
|2020-05-01|+31.75%|+28.92%|
|2013-01-03|+27.67%|+7.25%|
|2023-01-31|+26.51%|+26.66%|
|2010-09-16|+17.17%|+20.35%|
|2025-05-16|+15.94%|+19.65%|
|2006-08-29|+15.77%|+14.68%|
|2012-01-17|+8.49%|+8.49%|
|2023-11-21|+8.08%|+11.66%|

日进周出保留原始十大赢家合计交易收益约85%，优于此前用0.98×MA20动态盘中止损的约39%，但仍在2013和2016明显截断大趋势。盈利交易期间的峰值净值至退出的回吐中位数从A2约7.5个百分点降至约5.8个百分点；不同版本持仓长度不同，不能用该数字代替原趋势总收益。

尤其需关注2003-01-15入场：原始A2次日死叉退出，亏损约−1.75%；替换成周线退出后因日线死叉不再生效，到2003-01-28才触发N20保护，损失约−9.16%。这反映了周线确认较慢在部分行情中的真实代价。

## 排除2000年非金叉初始持仓的敏感性

原始历史59笔基准包含2000-01-03人为多头初始化。为避免该点主导结论，再仅允许真正的新金叉入场：

|策略|已平仓|统一Payoff|MDD|CAGR|
|---|---:|---:|---:|---:|
|A2原始|58|3.99|−20.3%|+5.84%|
|日进周出+N20|58|2.98|−26.3%|+5.38%|
|日进，日/周死叉谁先触发就卖|58|3.27|−20.3%|+5.27%|

对称周线方案的极端初期回撤部分来自初始持仓，但去除后仍显著大于A2，因此结论方向未变。

## 研究判断和边界

- A2追求的是少数趋势大赢家+低频+低回撤。周MA5/10对称进出并未同时改善任何上述核心目标；新增的周死叉早退也未优于原始A2。
- 周线指标减少一部分短期噪声，但在某些突然下跌中会因周末才确认而造成更大损失；“周线=风险更低”这一假设在此回测中不成立。
- 若研究重点仍是趋势内盈利保护，下一步应明确是否只在盈利很大时启用特殊退出、退出后是否允许回到同一趋势；不可在同一轮中同时修改入场、退出和重入来挑选最高指标。
- 真实止损单的执行价不保证等于触发价；这里是收盘确认后下一个开盘的机械成交模拟。样本只到2026-07-13，尚无独立样本外检验。
