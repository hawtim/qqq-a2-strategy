# V3.1-A · FAST 金叉资格延续 | QQQ / SPY 跨标的研究快照

**实验标签：** `EMA_V3_1_DEFERRED_FAST_CROSS_ASSET`  
**分支：** `research/v3-1-cross-asset-deferred-fast`  
**基线：** `EMA_V3_ADAPTIVE_N20_DAY0_CLOSE3`（在 `main` 冻结，不修改）  
**状态：** 样本内跨标的研究候选；**不**是新的正式 V3、不用于自动交易。

## 预先冻结的研究问题与规则

**问题：** 一次 *卖出之后* 出现的 EMA10/20 新金叉，如果因为月 EMA5 闸门未开放而未买入，能否保留该信号资格，避免因月初状态切换而漏掉持续上涨？

A 的**唯一策略差异**是 `defer_rejected_fast=True`：

1. 卖出成交之后获得 `eligible_fast=True`，没有卖出前留下的 FAST 资格；常规初次进场仍按原 V3。
2. 空仓时发生 **新的** EMA10>EMA20 金叉，如果月线减速否决，或上个完整月 EMA5 未上升，则标记 `deferred_fast=True`。
3. 只要 EMA10>EMA20 继续成立，即使不再出现第二次金叉，也可等待 **上个完整月 EMA5 上升** 且 **月线减速闸门打开**，在信号收盘后、**下一正常交易日开盘**入场。
4. EMA10/20 出现死叉或不再满足 EMA10>EMA20 时，取消候选。任何买入或卖出成交时，均重置 `deferred_fast`；特别是 **N20 卖出后不能复用持仓期间的旧金叉**。
5. 常规 EMA20/60 金叉及其原有延迟补买保留，常规与 FAST 同时有效时优先常规。不因 EMA20>EMA60 就禁止 FAST。
6. 完全保留 V3 的 **日末净亏损 7% 止损、EMA20/60 新死叉退出、常规 age=20 的条件式 N20 延期到 30 日、FAST 趋势确认后再保护 20 日、买入首日亏损 3% 次日开盘退出**。无任何新阈值优化。

**与 B 方案的边界：** A 不是“只要均线多头就无条件买”；没有 *卖出后出现的金叉* 或已登记的待恢复资格，不得凭 EMA10>EMA20 或 EMA20>EMA60 当前为正就重新买入。此前 SPY 试验中，B 的任意多头状态重入出现反复止损，未被采用。

### 新增或提前的 FAST 信号审计

下列 6 个为 QQQ 原 V3 不存在、A 候选实际发生的入场日期。表中净回报是新方案对应成交交易的结果，**不能视为对账户最终收益的可加性贡献**，因为它们改变了后续整条交易路径。

## 可复现的执行和文件

```bash
# SPY 等单段已规范化的 Yahoo-style Adj Close 日线：
python research/experiments/a2_v3_1_cross_asset.py \
  --symbol SPY --csv /local/SPY.csv --end 2026-07-23 \
  --outdir research/results/v3_1_spy_local

# QQQ：仓库文档中的两源拼接；只跑双方共同的截至 7 月 13 日快照：
python research/experiments/a2_v3_1_cross_asset.py \
  --symbol QQQ --old /local/qqq_jtang.csv --new /local/qqq_james.csv \
  --end 2026-07-13 --outdir research/results/v3_1_qqq_local

# 用户自备有权使用、已校验复权的 7 月后 QQQ 增量，可扩大至 11 月 9 日：
python research/experiments/a2_v3_1_cross_asset.py \
  --symbol QQQ --old /local/qqq_jtang.csv --new /local/qqq_james.csv \
  --update /local/qqq_update.csv --end 2026-11-09 \
  --outdir research/results/v3_1_qqq_2026_11_09_local

python -m unittest discover -s tests -v
```

输出文件：`summary.csv`、原 V3 与 V3.1 的完整已平仓交易账本、两套派生日末权益、`changed_trades.csv`、`candidate_only_completed_trades.csv`、含输入数据 SHA-256 的 `metadata.json`。代码不会将原始行情上传或输出。**汇总结果仅为已指定截止日的研究快照，不表示今日实盘仓位或自动交易授权。**

### 后续研究的证伪要求

- 必须使用同一份复权输入直接复现 SPY 和 QQQ 的基线，再比较候选；避免把不同截止日或不同数据供应商基准误作策略优势。
- 对 QQQ 2015-08-18 的微弱交叉施加正负极小价格扰动，检验候选是否仍依赖单日差值；不因为 MDD 与 CAGR 略优就忽略这一风险。
- 检查 A 的新增 FAST 买点在未来未知交易日中的盈亏，尤其是否出现 *先小止损、再买高价* 的路径劣化。
- 在这条分支上保存跨标的负面结果；在取得真正样本外验证前，**不合并为 `main` 的正式 V3 基准**。
