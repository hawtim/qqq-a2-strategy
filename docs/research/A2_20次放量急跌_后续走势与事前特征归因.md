# A2-N20：20次「单日跌≥3%且成交量≥1.2×」后的行情归因

研究日期：2026-11-09；阶段：**仅观察与归因，不改变任何交易规则**。

## 1. 样本和严格口径

- 核心策略始终是原始 A2-N20：QQQ 日线 MA20/60 新金叉次日开盘入场；N20 买入20个交易日内 MA10/20 新死叉且收盘浮亏则次日开盘退场；或 MA20/60 新死叉退出；退出后仅等待下一次新的 MA20/60 金叉。
- 本研究的事件只包括另外一条已回测候选 `QQQ 当天复权收盘较昨天复权收盘下跌≥3%` **且** `QQQ 当天成交量 / 前20个交易日平均量（不含当天）≥1.2`，次日开盘卖出。
- 2000-01-03—2026-07-13，共触发 **20次**：19笔与原始 A2 已完成的交易逐笔配对，另1笔（2026-06-05）对应原始 A2 在截止日尚未完成的仓位，不能赋予“卖对／卖错”标签。
- 「卖对／卖错」仅表示此次提前卖出的单笔实际平仓收益是否**高于**如果按原 A2 持有至其退出日的收益；这不是交易当时可知的标签，也不等同于后续 5／10／20 日是否上涨。
- 所有事前特征都只使用信号日及更早价格和量能。信号后的收益、创新低等严格当作**事后研究标签**。`t+N` 以**触发当天收盘价**为比较基点，不是下一日开盘的实际退出成交价。回测盈亏仍以次日开盘计入。

## 2. 暴跌之后究竟发生了什么？

| 信号后 | 收盘回升到信号日收盘之上 | 收盘累计收益中位数 | 期间再次跌破信号当日最低价 |
| --- | ---: | ---: | ---: |
| 5个交易日 | **13/20（65%）** | **+0.78%** | **16/20（80%）** |
| 10个交易日 | 10/20（50%） | -0.17% | **17/20（85%）** |
| 20个交易日 | **13/20（65%）** | +1.85% | **18/20（90%）** |

附：后续10日内最低价，相对信号收盘价的跌幅**中位数 -3.27%**；后续20日内最低价相对信号收盘价的跌幅**中位数 -5.58%**。在13个事件中，前5天一度有收盘反弹，但第6—20天又出现低于触发当天最低价的价格。

说明**短期反弹和更深的下探不是互斥状态**：只有终点收益不等于途中风险；不能把几天上涨等同于反转。

### 是否比平常更容易反弹？需要对照

| 研究人群／日期 | 观察样本 | 后5天上涨率 | 后10天上涨率 | 后10天破信号日低点率 |
| --- | ---: | ---: | ---: | ---: |
| 所有 QQQ 交易日（满足前后日期） | 6650天 | 57.4% | 59.6% | 77.1% |
| **原始 A2 持仓日** | 3442天 | 58.5% | 60.4% | 77.6% |
| 原始 A2 持仓且 QQQ 当日跌≥3% | 56天 | 67.9% | 55.4% | 80.4% |
| 本次实际触发的首个放量急跌事件 | **20次** | **65.0%** | **50.0%** | **85.0%** |

对照组日级窗口相互重叠，并不独立；这只是背景对照，不是随机对照试验。前5日反弹率 65% 比普通持仓日的 58.5% 仅高约6.5个百分点，以20次样本不足以证明“急跌越大，短期反弹概率越高”。

## 3. 事前指标能否判断这次应该退出？

可评分19笔中，**12笔提前卖出比原 A2 更好，7笔更差**。按事前已知信号分组：

| 事前特征 | 满足该条件：卖对/总数 | 不满足：卖对/总数 | 样本内判断 |
| --- | ---: | ---: | --- |
| 当日成交量≥前20日均量 **2倍** | 3/6 | 9/13 | 更大放量**没有**更高的卖对率 |
| MA60过去10交易日的斜率≤0 | 2/3 | 10/16 | 样本太少，未呈现明显分离 |
| 收盘价低于 MA60 | 5/8 | 7/11 | 基本没有区别 |
| MA200过去20交易日的斜率≤0 | 3/5 | 9/14 | 基本没有区别 |
| 急跌时持仓浮盈已≥8% | **1/4** | **11/15** | 成熟盈利仓更容易被提前退出误杀，但只有4笔 |
| 急跌当天跌幅已≥4% | **1/4** | **11/15** | 更剧烈跌幅不代表更值得马上卖，但只有4笔 |

样本内十个简单二元分组的探索性 Fisher 精确检验最小的双侧 p 值约 **0.117**，未发现可以单凭这组事前条件就可靠区分卖对/卖错的证据。这里同时测试了多个指标，不能把其中看起来好的数字作为正式过滤规则。

注意：「MA60向下」是过去10日 MA60 自身变化为负，与 MA20 新死叉并非同义；样本中的大多数事件发生时 MA60 仍在上升。

## 5. 比当日成交量更值得测试的线索：急跌后的短期方向

在19笔可配对交易中：

| 事后观察 | 提前卖出更优（12笔） | 提前卖出更差（7笔） |
| --- | ---: | ---: |
| 信号后2天收盘高于信号日 | **5/12** | **6/7** |
| 信号后5天收盘高于信号日 | 6/12 | 6/7 |
| 信号后10天收盘高于信号日 | **3/12** | **6/7** |
| 后10日收盘变化的中位数 | **-2.56%** | **+4.26%** |

这不是提前预测能力；它说明“卖错了”的交易确实更容易在急跌后快速恢复，而“卖对了”的事件更容易走弱。后两天收盘方向的分化，值得作为下一阶段的**两天观察窗口**假设进行独立回测，但如果真正等待确认，也必须承担这两天内继续下跌的风险，以及隔夜跳空、延后退出成本。

### 下一阶段可证伪的假设（尚未测试策略）

1. **H1：急跌不是直接卖出，而是触发2日观察状态。** 对照 t+1 立即卖出、持有观察2日后才根据价格是否收回信号收盘价采取退出；所有成交延后执行，保留原始 A2 再入场纪律。先核对2001和2020的假信号是否救回，2008、2009下跌是否损失扩大。
2. **H2：观察状态需要极端亏损兜底。** 在观察的2日内如出现更大下行，仍要通过独立固定风险阈值次日退出；不能以事后最佳低点作为止损价。新引入参数需单变量测试，不预设最优值。
3. **H3：成熟趋势与新入场保护分离。** 本次持仓浮盈≥8%的4个可评分事件，有3个提前退出更差，但样本极小；不应凭该特征修改策略，先延长数据并做样本外验证。

**截至本研究：没有发现能在暴跌当日可靠地区分“洗盘”与“趋势结束”的简单均线/成交量因子；原始 A2 仍是唯一主策略。**

## 6. 数据、独立检验与限制

- 根据用户提供的 GitHub QQQ 数据完成复权 OHLC 拼接，复核所有日期唯一、行情非空、成交量为正、价格高低有效。成交量倍数参考此前20日均量，含当前日成交量，仅在当天收盘后可确认；所有退出次日开盘发生。
- 原始 A2 末值 **$450,595.85**、新增规则末值 **$539,188.12**；重新复现20次退出、19笔可对照（12改善、7恶化），并交叉核对曝光日的前瞻收益分布。
- 本分析使用的是**「第一次触发候选规则的持仓交易」**，不是所有市场急跌日。由于早早退出会错过随后再次暴跌事件，存在条件性样本选择；全部普通持仓日的比较也有重叠窗口依赖。
- 样本只有19笔具有退出优劣标签，多指标筛选、市场环境转移以及历史数据商价格/量能修订都可使结论变化。尚未进行真正的滚动样本外和实际交易滑点检验。
