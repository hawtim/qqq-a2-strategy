# QQQ A2-N20｜入场初期亏损缓冲系数独立实验

研究日期：2026-11-09。历史样本：2000-01-03—2026-07-13，复权日 OHLC、单边0.05%手续费、$100,000初始权益、无额外滑点、现金无息。原始A2入场、MA20/60正常退出、新金叉重入及前20日有效期不变；**本次只修改N20原有“收盘价低于买入价”的阈值**。全样本探索，不是样本外验证。

## 一、改变的唯一参数

原始N20：买入后第1—20个交易日，如果日线MA10新下穿MA20，且当日完成收盘价 `Close < EntryPrice`，下一开盘全仓退出。

新参数 `b`（亏损缓冲）：将最后一个条件改成

```
Close < EntryPrice × (1 - b)
```

当日收盘确认，下一交易日开盘成交。`b=0`必须完全复现原始A2；越大的`b`代表允许价格跌得更深，才允许MA10/20新死叉触发N20。**这不是一个持续生效的固定百分比止损：只在新MA10/20死叉当日判断，错过这个交叉，次日继续跌不会自动触发。**

## 二、2003年原始信号的精确位置

|事件|日期|历史复权价格|
|---|---|---:|
|原始A2买入|2003-03-24开盘|$22.30455274|
|日MA10/20新死叉确认|2003-04-08收盘|$21.95907184|
|下一开盘按N20卖出|2003-04-09开盘|$21.992783|
|无N20持有到正常MA20/60死叉离场|2004-03-10开盘|收益+34.98%|

2003-04-08收盘相对于买入开盘价格是 **−1.5489255%**，不是最终卖出净收益的约−1.50%。

原本`b=1.50%`的门槛是`22.30455274 × 0.985 = $21.96998445`，信号收盘$21.95907仍低于门槛，触发N20。

`b=1.55%`的门槛是`22.30455274 × 0.9845 = $21.95883218`，信号收盘反而仅高出**$0.00023966复权价**，因此跳过N20。这个极细的边界和不同复权数据处理的差异，意味着事后选择的1.55%存在明显参数过拟合风险。

跳过止损并非立刻获利：2003-04-09收盘已经比买入价低约**3.82%**，2003-04-10盘中最低点约**−4.42%**；直到2003-04-17收盘才重新站上买入价。这是该策略原生“新死叉一次性判断”的风险。

作为历史起点敏感性检查，取消2000年非自然金叉的人工初始持仓后：原始A2的Payoff=3.99、MDD=−20.3%；缓冲1.55%的Payoff=2.97、MDD=−23.9%。方向仍然相同。

## 六、判断

按照原始A2目标优先级（高Payoff、低交易频率、低MDD），**没有发现一个足够稳健的正向固定亏损缓冲参数能够取代b=0的基准**。1.55%不应被宣称“最佳系数”，因为它恰好越过已经知道的2003年临界点，所有更小的缓冲都无法救回那笔交易。

下一步可以独立测试波动率归一化的缓冲（例如`EntryPrice - k × ATR14`）或针对N20退出后的趋势恢复重入，但不能在同一实验里同时修改止损触发和重入逻辑。
