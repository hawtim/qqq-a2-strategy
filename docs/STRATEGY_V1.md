## 0. 一页执行摘要

**策略目标**：用低频、确认后的多头趋势交易 QQQ；接受较低胜率与小亏损，努力持有少数较大涨幅，避免主观预测顶部和底部。它**不是保本策略，也不是高胜率入场策略**。历史回测胜率仅 41.38%；优势来自平均盈利远大于平均亏损。

| 事项 | 已冻结操作 |
|---|---|
| 信号频率 | 每个美股交易日收盘后检查一次；不根据盘前、盘中、新闻临时改规则 |
| 价格与均线 | QQQ 分红/拆分调整后的日线收盘价；MA10/20/60 为 SMA（简单平均） |
| 开仓 | **MA20 新上穿 MA60**，收盘确认；下一个正常美股交易日开盘买 QQQ |
| 入场前 20 日保护 | 从**买入后的下一个交易日**算第 1 日至第 20 日（含）；只有 **MA10 新下穿 MA20 且当日收盘低于该笔实际买入开盘价**，次日开盘退出 |
| 长期持仓退出 | 任何持仓日 **MA20 新下穿 MA60**，次日开盘退出；与 N20 同日触发时，以慢线退出为主因 |
| 重新入场 | 无论为何卖出，**必须等待下一次全新 MA20/60 金叉**；MA10/20 金叉不能单独买回 |
| 未触发卖出时 | 不减仓、不加仓、不因单日急跌而抛售；记录警报但不改变交易 |
| 模拟成交 | 信号只用当日收盘及此前信息；**次日开盘价**成交，按每边 0.05% 交易费，无滑点 |
| 当前可否直接给信号？ | **不可以**：已归档行情停在 2026-07-13。启动真实跟踪前必须把数据更新至最近一个完整美股交易日，并重建现有持仓状态。 |

## 1. 交易哲学与不做什么

1. **顺势，但确认较晚**：MA20/60 金叉不是底部买点。它可能已错过相当一段反弹；这是用较晚的进场换取趋势证据。
2. **收益分布右偏**：历史 58 笔中前 10 大赢家的正收益百分比总和占全部赢家的 **84.5%**。频繁退出、过度止盈可能错过主要收益来源。
3. **短期风险与中期趋势分开**：N20 只防范**买入头 20 个交易日短均线转弱且已低于买价**的失败走势；盈利持仓或第 21 天以后允许出现 MA10/20 死叉。
4. **不找神奇数字**：MA60 改成 61，某个 ATR 取 1.31 或止盈阈值定为 8%，都可能只是在历史行情上挑中了特定事件。
5. **不做空、不预测宏观新闻、不盘中猜顶、不在同一策略同时混入 TQQQ**。新闻与宏观可单独写观察笔记，不能倒灌为事后解释的交易信号。

## 2. 可执行的规则定义

### 2.1 输入与数学条件

用已经完整收盘的交易日 `t` 及以前的数据计算：

```text
C[t]        = QQQ 当日调整后收盘价
O[t]        = QQQ 当日调整后开盘价
MAk[t]      = mean(C[t-k+1 : t])，k=10/20/60

GOLD[t]     = MA20[t] > MA60[t] AND MA20[t-1] <= MA60[t-1]
DEATH[t]    = MA20[t] < MA60[t] AND MA20[t-1] >= MA60[t-1]
FAST_DEATH  = MA10[t] < MA20[t] AND MA10[t-1] >= MA20[t-1]
```

**强调：** `MA20 > MA60` 是多头状态，`GOLD` 才是*今天刚发生*的买入事件。不能持仓空仓期间只因 MA20 仍高于 MA60 就重新买入。反之 `MA10 < MA20` 不等于今天触发 N20，必须**新死叉**、在保护日内、且收盘低于实际入场价格。

### 2.2 状态机与信号优先级

| 当前状态 | 日收盘条件 | 次交易日开盘动作 | 后继状态 |
|---|---|---|---|
| `FLAT` 空仓 | `GOLD = true` | 买入 QQQ | `HOLD_N20` |
| `FLAT` 空仓 | 未出现新 `GOLD` | 无 | `FLAT` |
| `HOLD_N20` | `DEATH = true` | 全部卖出 | `FLAT` |
| `HOLD_N20`，且购入后第 1–20 日 | `FAST_DEATH = true` 且 `C[t] < entry_open` | 全部卖出，原因 N20 | `FLAT` |
| `HOLD_N20` | 没有满足以上任一 | 无 | 保护期届满后 `HOLD_TREND` |
| `HOLD_TREND`（第 21 日起） | `DEATH = true` | 全部卖出 | `FLAT` |
| `HOLD_TREND` | 仅 `FAST_DEATH` 或急跌、缩量、新闻等 | 无 | `HOLD_TREND` |

**执行时序**：信号在美东时间完整日 K 收盘后确认 → 标记 `PENDING_BUY` / `PENDING_SELL` → 下一**正常交易时段开盘**执行 → 录入实际成交价、费用、股数。不得在收盘后发现信号却假设同一收盘价成交。模拟中买入当天记为 `day_number=0`，**下一个交易日=1**，第 20 个交易日结束后转为长期持仓。卖出日开盘先执行已挂卖单，新的观察按当天收盘另行判定。

**跳空不是止损价承诺**：如果收盘信号触发，次日大幅跳空，交易结果以实际开盘可成交价计。N20 没有 2% 或 5% 硬止损，也不保证最大单笔亏损小于某值。若用市价/止损单，成交价格可能大幅偏离预期；限价单又可能不能成交（见 [美国 SEC 投资者教育：Order types](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders)）。

### 2.3 真实行情与历史复权价格差别

历史研究使用**拆分及现金分红统一调整的 OHLC**；实际券商显示的是当时原始报价。因此真实跟踪应优先使用持续更新、公司行动处理一致的日 K，并在计算均线和比较入场价时使用**同一个价格基准**。如果使用复权历史回测入场价，不能直接拿去与券商原始价格做 `C[t] < entry_open` 判断。可并行记录券商原价及调整因子，遇到分红/拆分复核信号一致性。

## 3. 研究证据：这份历史结果究竟验证了什么？

### 3.1 一项关键的真正因果对照：有无 N20

固定**完全相同的 58 个 MA20/60 金叉买点**，只关闭 N20 保护；其余条件不变：

| 指标 | **A2 含 N20** | 无 N20（只等 MA20/60 死叉） |
|---|---:|---:|
| 胜率 | 24/58 = **41.4%** | 28/58 = 48.3% |
| 平均赢家/输家比 | **4.02** | 2.18 |
| PF | **2.84** | 2.04 |
| 最大回撤 | **−20.29%** | −31.88% |
| CAGR | **5.84%** | 5.06% |
| 期末权益 | **$450,596** | $370,052 |
| 最大单笔亏损 | **−7.63%** | −11.39% |
| 持仓时间占比 | 51.90% | 65.02% |

**解读**：N20 **降低了单笔损失幅度和账户回撤，同时牺牲胜率**。本样本的作用不只是让信号更“正确”，而是用小亏换取风险控制。严格口径共有 **25 次 N20 出场：其中 16 次比不使用 N20 结果更好、9 次更差**。按各笔收益*百分点*相加净约 **+10.16 个百分点**，但**不是**账户净收益的百分点改善；完整复利差异以期末权益为准。

### 3.2 三个主要正例：持住赚钱趋势

| 买入 → 退出 | A2 净收益 | 持仓日 | 买入时条件 | 它证明什么；不能证明什么 |
|---|---:|---:|---|---|
| **2009-04-03 → 2010-02-09** | **+34.94%** | 214 | 买点在 MA200 下方，MA200 下降 | 熊市反弹也可能成为长期赢家；不能无差别过滤所有 MA200 下方金叉 |
| **2016-12-13 → 2018-04-06** | **+34.85%** | 329 | 价在 MA200 上方、长期线向上 | 真正长趋势贡献巨大；持续用 MA10/20 死叉卖出会牺牲大赢家 |
| **2020-05-01 → 2020-10-08** | **+31.75%** | 111 | 高波动率背景，价在 MA200 上方 | 即使途中 2020-06-11 单日跌 4.95%，继续持有最终更赚钱；急跌不等于趋势终结 |

另两笔关键赢家：**2013-01-03 → 2014-04-11 +27.67%**（320 日），**2023-01-31 → 2023-08-29 +26.51%**（145 日，买入时 MA200 下降且价格仍在其下）。仅五笔净收益都超过 20%，说明不能靠卖得快来保证策略的收益结构。**2025-05-16 → 2026-02-18 +15.94%** 也是慢趋势持有的正例。

### 3.3 N20 确实救回的正例

- **2001-05-10**：N20 在 2001-06-07 平仓 **−1.75%**；不启用 N20 则等到 06-27 **−8.94%**，改善 **+7.19pp**。
- **2004-04-23**：N20 **−0.45%**，仅等慢死叉为 **−6.59%**，改善 **+6.14pp**；“亏得还很少”是执行保护的原因，不是跳过保护的理由。
- **2008-08-26**：N20 由于次日跳空，实际平仓 **+0.65%**；不执行变 **−7.17%**，改善 **+7.82pp**。保护信号日浮亏不妨碍下个开盘反弹成交盈利。
- **2011-07-20**：N20 **−7.63%**，没保护会 **−9.20%**。这同时是 A2 最坏已完成单笔；保护也无法消除跳空/快速下跌。
- **2015-07-20**：N20 **−3.30%**，无 N20 **−11.39%**，改善 **+8.09pp**。
- **2022 熊市反复试错**：04-08 入场从 **−8.74%** 限制到 **−1.77%**；08-01 从 **−8.71%** 到 **−2.50%**；12-01 从 **−8.40%** 到 **−4.00%**。**2022 当年退出的四笔全部亏损**，其中一笔来自 2021 入场；策略仍有连续亏损的压力。

### 3.4 N20 误杀大赢家的反例（最重要的诚实审计）

- **2003-03-24 买入**：2003-04-09 N20 在 **−1.50%** 退出；如果**同一入场**不使用 N20，2004-03-10 才死叉卖，竟是 **+34.98%**。错失 **36.47 个百分点**；这是全套策略里最刺眼的误杀。
- **2020-10-12 买入**：2020-10-29 N20 **−6.13%**；不使用 N20 持到 2021-03-16 为 **+10.60%**，少赚 **16.73pp**。此前 2020-05-01 那笔大赢家刚在 2020-10-08 因极浅 MA20/60 假死叉退出，造成先卖、再买、再止损的组合损害。
- **2012-07-17**：N20 **−0.15%**，无 N20 **+3.59%**；**2015-02-18**：−1.20% 对 +0.89%；**2021-04-13**：−2.90% 对 −1.04%。小亏保护常会错过后续回升。

这些反例不是要废除 N20：全历史因果对照显示**去掉保护反而把最大回撤从约 −20% 拉大至 −32%**。如果为救 2003/2020 调松规则，必须验证是否会重伤 2001/2004/2008/2015/2022 等多笔止损。

### 3.5 MA20/60 退出不是卖在顶部：2020 年和“假死叉”

2020-10-07 日线出现 MA20 略低于 MA60（约 **264.438 vs 264.575**）；MA20 同日仍高于 MA61（约 **264.362**）。原 A2 10-08 开盘退出 **+31.75%**，10-12 新金叉后再入场，10-29 N20 −6.13%。若改为 MA20/61，2020 这段会持续持有至 2021-03，单笔约 **+50.07%**。**但这是一个日期边界的高敏感个例，不是 61 日线优于 60 日线的证据**；MA20/62 等相邻周期也存在不同回撤和胜负分布。

### 4.1 两个被验证的“额外退出反而更坏”反例

**2001-05-10：** 原 A2 N20 于 06-07 卖出 **−1.75%**；“急跌直接卖 + 快速买回”的 C 方案在 05-31 先卖 **−7.15%**，06-06 买回后又在 06-15 急跌卖出 **−13.15%**。全部是**做多**，亏损扩大来自**更差的出场时点 + 随后的重复试错**，不涉及做空。

**2020-05-01：** QQQ 2020-06-11 单日 **−4.95%**、量约 **1.71×**。直接卖出只留下 **+11.35%**，原 A2 到 10-08 可得 **+31.75%**，相差约 **20.40pp**。2020-09-03 的急跌同样可以提前保护，但“遇到急跌全走”并不构成稳健的统一规则。

### 4.2 B 两日观察为何保留为影子策略

**触发口径（只在已经持有 A2 仓位时）**：当日 QQQ 收盘较前一日跌 **≥3%**，且当日成交量 / **前 20 个完整交易日**（不包含今天）平均成交量 **≥1.2**，记作 `SHOCK_DAY=T`。随后两个完整交易日不因额外警报卖出；若 T+2 收盘价仍低于 T 收盘价，则下一交易日 T+3 开盘发出 B **额外卖出**，否则取消观察。期间原有 N20 和 MA20/60 死叉照常执行，不能为等待反弹暂停它们。**A2 V1.0 当下只记录，不发 B 订单**。

| 完整样本 | A2 原版 | B 两日观察 |
|---|---:|---:|
| 已平仓 | 58 | 58 |
| Payoff / PF | **4.02 / 2.84** | **4.19 / 3.18** |
| MDD | **−20.29%** | **−20.90%**（更差） |
| CAGR | **5.84%** | **6.42%** |
| 期末权益 | $450,596 | $520,844 |
| 25 次观察后的处理 | 不适用 | 9 额外退出 / 14 恢复 / 2 被 A2 出场接管 |

**9 次 B 额外卖出的全部正反例**（与 A2 原版同入场日期比，百分点为交易收益差）：

| 入场日期 | A2 原收益 | B 原收益 | 改善/损害 |
|---|---:|---:|---:|
| 2000-08-31 | −6.62% | −5.24% | **+1.38pp** |
| 2001-11-07 | +2.00% | +3.59% | **+1.59pp** |
| 2007-02-16 | −4.86% | −4.31% | **+0.56pp** |
| 2007-09-18 | +3.08% | +0.56% | **−2.52pp** |
| 2008-04-10 | +0.08% | +7.70% | **+7.62pp** |
| 2010-03-11 | −4.75% | −1.78% | **+2.98pp** |

| 2024-05-22 | −3.23% | +2.18% | **+5.41pp** |

历史 25 次 B 观察里，两日收复原跌幅 **不足 25% 的 14 次**，在观察结束后的 **5 个交易日内有 14/14 再次跌破急跌日盘中低点**；收复 **≥25% 的 11 次**，仅 **3/11** 在后5日破低；后20日破低升至 **6/11**。这是**近期再试低点的分布**，并非 14/14 都在 20 日后亏损；而且 25% 是回看历史找到的分组界线，不能直接用来实盘止损。反弹期间量能比在这25例中没有明显区分力。

**最关键的反例**：2001-05-30 暴跌后两日收复 **95.9%**，之后仍再破低；2020-09-03 两日走势**继续下跌**，但第20天收盘又回升至观察末日之上。因此“反弹弱 = 永远跌”“反弹强 = 不会再跌”都不成立。样本相关、观察重复、参数后选以及 2010–2025 子样本 B 的 Payoff 不如 A2，意味着 **B 还不是经样本外证实的正式交易规则**。

## 5. 账户层面：为什么单笔最大亏损 −7.63%，MDD 却有 −20.29%？

**单笔亏损** = 一次成交价格之间的扣费亏损；**MDD** = 每个交易日的账户权益（包含尚未卖出的浮盈亏）相对于此前账户最高值的最大下降。

- 一笔此前盈利很多的仓位后退，虽然最后仍是盈利交易，也会让账户从峰值回落；2020-09-02 的 TQQQ 示例从峰值至 10-08 因大波动曾跌逾 20%，即使 10-08 卖出仍是赚钱单。
- 连续亏损按权益**复利叠加**，不能拿单笔最差作为账户安全上限；A2 历史最长连续亏损 5 笔。
- **严格 QQQ A2 历史 MDD −20.29% 的最低点为 2011-11-25**。这和 TQQQ 在 2020—2023 年出现的 **−54.34%** 不是同一策略资产风险。
- 最大回撤也不是可预先保证的上界；样本外、跳空、手续费/买卖差价变化都会改写结果。

**真实账户的仓位建议作为独立风险预算**：回测假设账户 100% QQQ 是为了比较规则，**不等于建议实际把全部可投资资产投入**。实际若只划定某个独立策略袖珍仓位，应将策略袖珍仓位 MDD 与家庭总资产 MDD 分开追踪；不允许因连续胜利逐步提高杠杆。“N20 保护”不是经纪商托管的保证止损单。

## 6. 真实跟踪 SOP（可以明天开始执行）

### 6.1 启动前：重建当前状态，不能猜自己空仓

1. 更新 QQQ 调整后 OHLCV 到**最近一个已完成的美股日 K**；核对日期、停牌/节假日、数据源公司行动/分红记录。
2. 从历史最早可用日期**按状态机逐日完整重放**，确认截至最新收盘 A2 究竟是 `FLAT`、`HOLD_N20` 还是 `HOLD_TREND`。因为 2026-07-13 仍有一笔 2026-04-23 开始的**在途仓位**，2026-11 不可无条件当作空仓等金叉。
3. 初次开始时，如果策略历史上已持仓而个人账户未持仓：**只记录影子仓位，不得临时以“现在 MA20>60”追买并称为 A2**。实际参与须从未来可执行的新信号开始，或者另立带仓初始化实验。
4. 确定纸面模拟本金、单次投入金额、行情源、信号时间戳（美东时区）、执行经纪商及订单类型，冻结版本为 `A2-N20 V1.0`。

### 6.2 每个交易日的监控流程

| 时点 | 必做事项 | 输出字段 |
|---|---|---|
| 完整美股日 K 收盘、数据到齐后 | 更新调整后 OHLCV 和 SMA10/20/60；检测 `GOLD/DEATH/FAST_DEATH` | `market_date`, `data_timestamp`, `ma10/20/60`, `cross_state` |
| 运行策略状态机 | 检查持仓、保护期天数、入场开盘价格、优先级 | `position_state`, `entry_date`, `n20_day`, `signal_reason` |
| 如有真实买卖信号 | 生成下一交易日开盘的待执行指令；核对美股假日 | `order_date`, `order_side`, `planned_fraction` |
| 次日常规交易开盘 | 记录实际成交价、股数、费率、滑点；若未成交，**标记异常**，不可假装按开盘价填了 | `fill_price`, `filled_qty`, `fees`, `slippage`, `execution_status` |
| 日末复盘 | 记录策略权益、新高与回撤，**B 警报只读**，不改变 V1.0 仓位 | `strategy_equity`, `peak_equity`, `drawdown`, `shadow_B_state` |

### 6.3 同时留三本账

- **Signal Log**：每天只有一条 QQQ 收盘观察记录；无信号也记录，防止挑选性记录。
- **Trade Ledger**：每次买卖的信号日、计划执行日、真实执行日、原始/调整价、费用、股数、止损原因；用唯一 `trade_id` 关联入场出场。
- **Equity / Risk Ledger**：每日收盘账户净值、历史最高、历史回撤、现金比重、未实现盈亏、独立的 B 观察状态；不用单笔盈利掩盖账户亏损。

附带文件中有 `A2_daily_signal_template.csv`、`A2_trade_journal_template.csv`、历史逐笔明细、权益曲线及反事实事件表。**反事实改进的盈亏比、价格路径、新闻标签都是离线研究数据，不能进入线上信号计算器。**

### 6.4 异常处理与审计

- **缺少最近收盘价或成交量**：冻结当日决策、报警、恢复数据再计算；不拿 30 分钟或盘前价模拟日线收盘。
- **复权前后价差异常或行情源变更**：保留两源及调整系数、复算近 60 日均线；记录是否出现“跨源假金叉”。
- **开盘前已跳空**：按实际成交价记账，不能按昨收或假设止损点计算；若无法成交，另记 `MISSED_FILL` 并进入人工核查，不得在日志中悄悄回补理想价。
- **策略已持仓但资金/份额不足**：执行交易与信号分两层审计，标记 `PARTIAL_FILL`；研究信号不因此更改。
- **日线交叉极接近零、均线缠绕**：默认按数学规则执行；记录 `ma20_ma60_spread` 和 `crosses_past20`，**不在 V1.0 引入临时宽容带**。
- **持仓期间发生大跌且出现 B 观察信号**：记录 `shadow_B`，执行策略仍以 A2 的 N20 / MA20/60 为准；除非在独立研究后明确升级版本。
- **总资金承受能力发生变化**：调整的是**外部预算/真实交易规模**，不是回写历史规则让回测看起来更稳。

## 7. 避免历史过拟合：版本治理与验收门槛

**V1.0 固定所有参数**：`MA10/20/60`、`N=20`、收盘确认/次开盘、全新金叉、亏损判定、基础资产 QQQ。任何加一条（MA200 判断、5% 崩跌、B 观察后退出、快买回、TQQQ 等）都必须叫 `A2-candidate-...`，与 V1.0 **并行模拟**，不能直接更名为 A2。

候选规则要满足：

1. 明确事前假设和输入字段，无需新闻后视镜、无需未来 K 线；所有订单延迟、费用、滑点被模拟。
2. 在**相同起始本金、相同数据截止、相同可交易时间段**报告 Payoff、PF、净收益 CAGR、MDD、最差单笔、连续损失、胜率、交易次数、空仓比例；不得只用一两个赢家评估。
3. 明确列出**每一笔被改善的案例和每一笔被误杀的案例**，给出账户而非单笔百分比之和。
4. 先做时间上未参与规则挑选的前瞻影子跟踪（应按季度看，策略一年仅约2笔），再进行其他指数/不同成本假设稳定性测试。
5. 在真实跟踪过程里不追溯重算为“当时应该”的理想成交；版本升级从新的生效日期开始。

**观察维度与决策维度分离**：`MA200`、ATR、成交量放大 1.2 倍、过去 20 日均线交叉次数、B 两日反弹收复比例，都可以在监控仪表盘显示，但它们当前不会触发 A2 V1.0 的买卖。

## 8. 明确哪些事情还没验证

- 2000—2026 是**单条历史市场路径**，不同候选阈值在同一数据上反复探索，**不是**多个独立样本。
- 2026-07-14 至 2026-11-10 的真实市场波动**不在已冻结研究数据库里**；任何“这几天满足 A2/B”都必须用新行情重新核对。尤其不能拿 11 月事件当作旧 25 笔统计中的一笔。
- A2 收益是趋势择时与留现金的合成结果。**未在同口径下全面比较税后、现金国债替代收益、QQQ 总回报买入并持有**；不应声称本策略已战胜长期持有。
- 回测 0.05%/边只是假设，缺少开盘滑点、冲击成本、汇率/税务、分红处理差异、实际银行资金划拨及券商订单故障压力测试。
- B 的两天观察确实有针对弱反弹/近五日破低的**探索性相关性**，但没有证明能降低最大回撤，特别是 TQQQ 的 B MDD 比 A2 更深。
- 历史 TQQQ 单笔平均盈亏比不错，也会出现 **−54.34%** 级别的账户 MDD；3 倍日杠杆**不是三倍长期收益**（FINRA 关于 [日杠杆 ETF 重置和复利路径风险](https://syndication.finra.org/content/lowdown-leveraged-and-inverse-exchange-traded-products)）。
