**为何多数候选不加入**：同一数据集被反复观察，指标改进可能来自2003/2020的少数边界事件。止盈通常减少部分回撤也会缩短少数盈利大单；更少交易不等于更低的账户 MDD；更早退出还会导致下一次无法及时恢复仓位。

### 独立基准：QQQ 首日买入并持有（不修改 A2）

[同口径买入持有与税务边界完整报告](research/A2_QQQ买入持有基准_回撤与税务口径_2026-11-10.md) 单独复现了 $100k 首日复权开盘价买入（0.05% 初始交易费）、持有到截止日不卖出的价格路径：冻结到2026-07-13 **$877,700、CAGR8.53%、MDD−82.96%**；更新到2026-11-09 **$838,629、CAGR8.24%、MDD−82.96%**。相同时间窗口 A2 终值分别 **$450,596 / $436,163**，MDD 均 **−20.29%**。QQQ 的 2000-03-27 历史收盘峰值直到 2015-02-20 才在税前分红再投资代理下恢复，水下约14.9年。**这一对照证实本样本的回撤/终值权衡，不证明策略未来有固定下行上限。**

来源是与 A2 相同的本地已授权 QQQ 日线，派生统计保存在 [JSON](../research/results/a2_vs_buy_hold_2026_07_13_and_11_09.json)，[月度权益与回撤](../research/results/a2_vs_buy_hold_monthly_equity.csv) 和 [静态 SVG](../assets/a2_vs_buy_hold_equity_drawdown.svg)。**所有指标税前**，个人资本利得税、分红预扣税、税务居民身份与是否末期卖出，都不能简单套一个固定税率。

## 三、必须保留的反向证据

- **2003 N20 误杀**：2003-03-24 买入，04-09 −1.50%卖，不用保护2004-03-10可以+34.98%；不因它就删掉 N20 的防守案例。
- **2020 极浅MA20/60死叉**：2020-10-08 +31.75%卖，10-12买回，10-29 N20−6.13%；MA61策略持有更久，但极可能是过拟合 MA61 神奇阈值。
- **2020-06-11 放量急跌误卖**：原A2持至10-08 +31.75%；急跌立即卖只能+11.35%，损失20.40pp。
- **2001 C双重失误**：急跌提前卖 −7.15%，之后重买又 −13.15%；没做空也可能因多次重入导致更多亏损。
- **2001/2004/2008/2015/2022 N20 救回**：不等待大概率后续反弹，实际止损与反事实差异在 `research/results/A2_N20_25_counterfactual.csv` 每笔可查。
- **B不是安全版**：QQQ MDD反而由−20.29%到−20.90%；2010–25同期间 QQQ B Payoff 低于 A2；TQQQ B MDD 从−54.34%到−56.77%。
- **2000合成首仓**：旧快重入“2020年以前的2000 +22.02%浮盈”不是严格 A2 的天然交易，不能为此调出一个完美止盈规则。
- **RE-01/02 快速收复并非趋势恢复**：21次重新买入中13次在止损当天收复，却只有4次赚钱；在2001年更早的MA20/30、MA20/50退出反而比MA20/60亏得更多。不能把“均线退出更快”直接等同于“单笔亏损或账户MDD更低”。

## 五、下一次新增研究的最低标准

1. 给候选起新名字与版本，预先写明假设、交易日定义、订单时点、再入场规则。
2. 对原A2 **58个同源入场信号**和每一个改变的赢家/输家逐笔配对；允许新规则改变后续入场时，应提供完整账户曲线对照。
3. 必须看：Payoff、PF、CAGR、**每日权益MDD**、最大亏损、连续亏损、交易次数、空仓时间、滑点敏感度。
4. 测试不同年代、其它指数与真正未参与参数挑选的新时期；发生变更要保留版本差分。
5. 不允许把“过去20日破过低点”直接表述为“未来20日亏损概率”，也不能把股价反弹与实盘可成交收益混为一谈。
