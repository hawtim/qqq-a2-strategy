# H3 Profit Guard A/B v1.0 — 冻结研究候选规则（2026-11-13）

## 1. 同一个底层 H3

- 交易标的：初始指定 **QQQ 日线**，使用完成收盘 K 线的拆分/分红一致复权 OHLC。
- H3 自己计算交易窗口与入场、退出，按原有月线过滤、N20、7%净亏收盘止损、EMA20/60 慢死叉等执行。
- 叠加层使用 **H3 影子持仓（shadow)**：提前卖出时实际账户空仓，但原 H3 继续仿真原持仓状态和原定退出。实际账户不得延长原 H3 窗口；下一次原 H3 入场时间不因叠加层买卖而改变。
- 若原 H3 下个开盘已经安排卖出，原定卖出优先；不得增加同开盘的冗余保护卖单。任何已有的 overlay 待执行单在原 H3 强制退出时取消。原 H3 全部卖出后取消特殊重入资格；下一次 H3 原开仓重置保护次数与以**新 H3 买入开盘价**为锚的最高浮盈。
- 无卖空、无杠杆、没有独立于原 H3 的新大趋势入场；现金与全仓二态；额外卖出和再买各最多 **1 次/原 H3 入场窗口**（如果已经额外卖出，买回后第二次死叉也不能再额外卖出）。

## 2. 完全相同的公共保护开关

从持仓当日收盘起，不设置「至少持仓10天」等时间门槛（**age minimum=0**）。

截至交易日 t 收盘：

- 当前实际有仓位，且 H3 shadow 持仓未结束；
- 最高**已完成收盘**毛浮盈 `peak(t)=max_{j in [entry,t]} (AdjClose[j]/AdjEntryOpen-1)` **≥10%**；
- **当前**完成收盘毛浮盈 `AdjClose[t]/AdjEntryOpen-1 > 0`；
- 完成收盘 `EMA20[t] > EMA60[t]`；
- 本次原 H3 交易尚未用过特别卖出权限；
- 下个开盘并非原 H3 已安排的卖出。

注意：这些条件是**附加退出条件**，不是强制卖出的独立触发器；无交叉信号则维持 H3。最高浮盈用截至当日已知的历史最大收盘价，不用未来/盘中峰值。先前研究的“利润吐回≥50%”只是**事后评价指标**，不属于交易发单规则。

## 3. A v1.0 — 普通 EMA5/20 死叉利润保护

当公共保护开关全部满足、并且当日出现**新鲜**死叉：

```python
death_5_20 = EMA5[t] < EMA20[t] and EMA5[t-1] >= EMA20[t-1]
```

则**下一常规交易日复权开盘价**全额卖出，扣单边0.05%佣金。EMA10/20 是否仍多头、三日下跌速度，**均不额外过滤**。

版本 ID：`H3_PG_A_V1_AGE0_CAP1`

## 4. B v1.0 — 在 A 基础上选择性防范快速下跌

保持 A 所有条件，还须同时满足：

```python
EMA10[t] > EMA20[t]                # EMA10/20 还未进入死叉态
ATR20[t] = SMA20( TrueRange[completed daily bar] )
fast_decline = (AdjClose[t-3] - AdjClose[t]) / ATR20[t] >= 1.5
```

True Range 为 `max(AdjHigh-AdjLow, |AdjHigh-prev AdjClose|, |AdjLow-prev AdjClose|)`；EMA 用 `ewm(adjust=False)`，正确的历史预热；**当日完整 K 线可以用于当日收盘信号，但不可在当日收盘价成交**。须同时有 A 的新鲜 EMA5/20 死叉，才在下一常规开盘卖出。不能把“3日大跌”单独当卖单。

版本 ID：`H3_PG_B_V1_AGE0_CAP1`

## 5. A/B 共同的唯一一次特殊重新入场

上一次特殊卖出后，持有无息美元现金；只有下列条件在已完成收盘时**同时成立**：

```python
gold_5_10 = EMA5[t] > EMA10[t] and EMA5[t-1] <= EMA10[t-1]
H3_shadow_still_long = True
EMA20[t] > EMA60[t]
```

才在**次一常规开盘**以全部现金买回，扣单边0.05%费用；不要求价格低于之前的卖出价；也不额外要求月线重新放行（**特殊重入授权**与原 H3 新入场资格不同，开发不可偷换）。

如果原 H3 的退出先到且尚未买回，则持有现金至下一次原 H3 新入场；如果先买回，则继续持有至原 H3 原退出，期间不允许第二次特别卖出。

如果同一日发生原 H3 退出信号，其下个开盘订单优先。多次信号、未执行待订单、跨周末 / 假期要保证一次执行，不在收盘假设成交。

## 7. 明确的失败证据，防止只记住漂亮回测

- A：28笔触发退出，只有11笔相对 H3 提升收益，17笔更差；18笔提前卖出后实际再买，只有1笔最终更好。
- B：22笔提前退出，仅10笔相对H3更好，12笔更差；**B的12笔特殊重新入场全部使单笔净收益更差**。10笔好交易都是卖出后保持空仓直至原H3结束。
- 2010-2019与2020-2026时期，B&H 的区间累计收益都大幅超过 A/B/H3；2000起点的整体超越受到科网泡沫崩盘影响。
- 放开每个H3窗口额外2次或无限次出入，历史CAGR均劣于最多1次；禁止在 v1.0 静默放开。
- B 没有降低冻结 H3 的约−24.30%账户MDD；2022全年B与H3均约−21.20%，A约−14.95%。
- **A/B 仅冻结为可重现的研究方案，不宣称顶部分辨具有统计显著性、未来必然跑赢 B&H、或已解决提前卖出后的重入问题。**
