# QQQ EMA 趋势策略 V3｜当前选定研究基准

**版本号：`EMA_V3_ADAPTIVE_N20_DAY0_CLOSE3`**
**决策日期：2026-11-11；状态：用户选定研究/模拟跟踪基准，非实盘交易授权。**

V3 在已归档 V2 上只增加**常规入场的条件式 N20 延期**和**买入首日收盘亏损 3% 退出**。保留原 V2、第四方案、冻结 SMA V1 和每一套旧交易账本；不得把 V3 的规则回写旧基线。唯一固定执行入口：`research/experiments/a2_v3_selected.py` 中的 `replay_selected_v3()`。

## 1. 不变的原 V2 规则

1. 标的 QQQ；EMA10/20/60 以复权日收盘递归计算；月 EMA5 只用**上一个已完成月**及更早月份，严禁取未完结月的最终月末值。
2. 空仓时：新 EMA20/60 金叉可以买入；如果上一个已完成月 EMA5 仍上升但上升斜率小于上上月，则**暂缓**常规金叉买入。在 EMA20>EMA60 的多头区间保持有效时，月线闸门恢复可在下一开盘补买；死叉则清除待补买资格。
3. 任意退出后可重新等待 FAST 买点：新 EMA10/20 金叉且上个完整月 EMA5 上升、月线闸门开放；常规金叉与 FAST 同时触发时优先常规。
4. 每个入场日 `age=0` 当天收盘即检查原 N20：新 EMA10/20 死叉且收盘低于该笔真实复权买入开盘价，发出卖单，**次日正常开盘**退出。
5. FAST 入场的动态 N20 不变：在慢 EMA20/60 趋势确认前持续保护；确认后再保护 20 个完整交易日。常规入场原保护期为 `age=0..20`。
6. 全程 `EMA20/60` 新死叉退出、全程 **7% 净亏损收盘止损**维持不变。7% 触发价按买卖两次各 0.05% 手续费计算，不保证次日开盘实际亏损不超过 7%。

完整入场状态机详见冻结的 [V2 定义](STRATEGY_CANDIDATE_V2.md)。

## 2. 新规则 A：常规 N20 条件延期

只对 `REGULAR_EMA20_60` 入场生效；FAST 不修改。在持仓 `age=20` 的**完成收盘**时，计算以下条件：

```python
underwater_closes = sum(close[k] < entry_open for k in last_5_completed_sessions)
spread_now = EMA10_today / EMA20_today - 1
spread_five_sessions_ago = EMA10_five_days_ago / EMA20_five_days_ago - 1
extend = underwater_closes >= 2 and spread_now < spread_five_sessions_ago
```

- `extend=False`：常规 N20 按原定 `age=20` 到期。
- `extend=True`：**当时一次性记录延长资格**，允许 N20 继续到 `age=30`（含）；仍须在适用期内有**新的** EMA10/20 死叉，且当天收盘低于入场价，才可在下一开盘退出。
- 延期不等于「EMA10 始终低于 EMA20 就直接卖出」；延长期间价格恢复时不会因为这条规则卖出。任何时间的 7% 收盘止损和慢均线死叉退出仍有效。
- `age=25` 和 `age=35` 的替代截止日已经做过敏感性分析；截至 2026-11-09 的历史交易路径相同，但未来不同。

此条件在看过 2011 的失败案例后提出，**是样本内研究而非经独立验证的预测规律**。

## 3. 新规则 B：买入首日亏损 3%，次开盘退出

只在 `age=0` 当天检查：

```text
entry_day_close_guard = (adjusted_close_of_entry_day <= 0.97 * adjusted_entry_open)
```

若成立，已完成收盘形成卖出信号，在**下一个正常交易日调整后开盘价**成交；不得假设发出信号后仍能以触发当天的收盘价卖出。这里 **3% 按买入到当日收盘的价格跌幅定义，尚不含双边费用**；全程 7% 收盘止损按包含费用的净损失定义，二者口径刻意区分。

**同日优先级**：全程 7% 收盘止损 > 慢 EMA20/60 死叉 > 有效 N20 新死叉 > 首日 3% 收盘亏损保护。每个信号只生成下一交易日的一张卖单。

不采用盘中止损单：现有日 K 只能确认最低价是否触达 3%，不能证明实际成交流动性、停牌、滑点和订单是否能被及时执行；分钟数据到手后可另立实验。

## 5. 为什么不选表现更好的 4% 收盘止损

在同一份历史数据中反复比较 4%/5%/6%/7%/8% 止损后发现，4% 结果最好；但这属于**样本内参数选择偏差的警示案例**，不能由高分推出未来也是最优。

- 回测中 4% 比 7% 提前退出了数笔失败交易，历史上没有截断后来的盈利交易；但未来可能有相反情况，尤其阈值靠近正常回撤波动时。
- 4% 是**收盘触发、次日开盘退出**，不是精确固定损失上限；历史最差单笔仍 −6.08%。
- 2011 年这笔失败，4% 止损与 V3 条件 N20 都在 2011-11-18 收盘触发，2011-11-21 开盘成交；在 4% 止损方案上再加动态 N20 **完全没有新增效果**。
- 当前选择 V3 是研究判断与执行可解释性的取舍，**不是证实 V3 比 4% 必然更稳健**。同样，V3 的「3% 首日」和「2/5 + EMA 斜率」仍有已知样本依赖性，不能自称已经免于过拟合。

**决策**：冻结 4% 为失败风险/负面对照，不进入 V3 选定参数；保留 7% 原兜底。未来复核必须包含 4% 对照与 V2 基线，并重点检验新交易、跨行情源、阈值局部扰动及未来样本。
